# 1106 바이브코딩 실습 저장소

「AI 바이브코딩 실습」 강의를 운영하는 저장소입니다. 강의에서 쓰는 **예제**와 여러분이 만든 **과제 제출본**이 모두 여기에 모입니다.

- 강사가 만든 예시 확장 프로그램을 내려받아 바로 설치해 볼 수 있습니다.
- 라운드마다 만든 확장 프로그램을 내 닉네임 폴더에 올립니다.
- 올린 결과는 강사 대시보드에 갤러리로 모여서, 수업 중에 함께 봅니다.

> 수강생 초대가 끝나면 이 저장소는 **비공개(private)** 로 바뀝니다. 그 뒤에는 초대받은 사람만 볼 수 있어요.

## 폴더 구성

```
[강사예시]/            ← 강사 예시. 내려받아 설치해 보는 곳 (고치지 않아요)
├── 01_기본-todo/
├── 02_메일-todo/
└── 03_팀-소개-페이지/   ← 2라운드 팀 홈페이지 예시
[강사스킬]/            ← 대화로 기획하고 만드는 스킬 2종 (고치지 않아요)
├── team-page-prd/
└── work-os-builder/
round1/               ← 1라운드 과제
├── 닉네임A/
│   ├── manifest.json
│   ├── ...
│   └── screenshot.png
└── 닉네임B/
round2/               ← 2라운드 과제 · 팀 홈페이지
round3/               ← 3라운드 과제
```

| 폴더 | 언제 올리나 | 무엇을 |
|---|---|---|
| [[강사예시]]([강사예시]) | 올리지 않음 | 강사가 만든 예시. 내려받아서 설치·비교해 보세요 |
| [[강사스킬]]([강사스킬]) | 올리지 않음 | 팀 홈페이지 PRD 제작기 · 나만의 업무 OS 스킬. 설치법은 폴더 안 안내 참고 |
| [round1](round1) | 1라운드 끝 | 설치해 보고 Codex로 처음 고친 할 일 작성기 |
| [round2](round2) | 2라운드 끝 | **팀 홈페이지** · 기획서 `prd.md` + 로고 `logo.png` + 버셀 링크(`README.md`) ([안내](round2/README.md)) |
| [round3](round3) | 3라운드 끝 | 내가 원하는 기능으로 완성한 확장 프로그램 |

## 꼭 지켜 주세요: 개인정보 · 회사 정보

- **실명 대신 닉네임**을 씁니다. 폴더 이름, 화면 문구, 스크린샷 어디에도 실명을 넣지 않아요.
- **회사 정보는 넣지 않습니다.** 회사 이름, 부서, 사내 시스템 주소, 고객 정보, 내부 자료 모두 해당돼요.
- **연락처 · 비밀번호 · API 키**는 넣지 않습니다.
- 스크린샷에 메일 제목, 메신저 내용, 다른 탭이 찍히지 않았는지 올리기 전에 한 번 더 봅니다.
- 올린 기록(커밋)에는 깃허브 아이디와 프로필 이름이 남습니다. 실명을 드러내고 싶지 않다면 깃허브 프로필 이름을 비워 두세요.

애매하면 가짜 이름, 가짜 번호로 바꿔서 올립니다.

## 닉네임 정하기

- 한글·영문·숫자 모두 됩니다. 띄어쓰기 대신 `-` 를 써 주세요. 예) `할일요정`, `todo-master`
- 올리기 전에 해당 라운드 폴더를 열어서 **같은 닉네임이 없는지** 확인합니다.
- 세 라운드 모두 **같은 닉네임**을 씁니다. 그래야 대시보드에서 내 작업이 한 줄로 이어져 보여요.

## 강사 예시 받기

- **가장 쉬운 방법**: 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기 → `[강사예시]` 안의 폴더를 크롬에 설치
- **git을 쓴다면**: 처음엔 `git clone`, 그 뒤로는 `git pull` 하면 새 예시가 내려옵니다.

크롬 설치: 주소창에 `chrome://extensions` → 개발자 모드 켜기 → 「압축해제된 확장 프로그램 로드」 → 폴더 선택

> **2라운드는 팀 홈페이지**를 올려요. 올릴 파일이 달라서 [round2 안내](round2/README.md)를 따로 봐 주세요. Codex에게 "2과제 내고 싶어"라고 말하면 [`AGENTS.md`](AGENTS.md) 순서대로 같이 준비해서 올려 줍니다.

## 과제 올리기 (1·3라운드 · 확장 프로그램)

1. **초대 수락** (처음 한 번만): 깃허브 가입 메일로 온 초대장에서 **Accept invitation**
2. **폴더 이름 바꾸기**: 내 확장 프로그램 폴더를 복사해서, 이름을 **내 닉네임**으로 바꾸기
3. **스크린샷 넣기**: 확장 프로그램 화면을 캡처해서 그 폴더 안에 `screenshot.png` 로 저장 (더 보여 줄 장면은 `screenshot-2.png`, `screenshot-3.png`)
   **소개 글 넣기**: 라운드 폴더의 `_양식/README.md` 를 내 폴더에 복사해서 채우기. 자세한 건 각 라운드 폴더 안내 참고
4. **올리기**: 이번 라운드 폴더(예: `round1`) 클릭 → **Add file** → **Upload files** → 내 닉네임 폴더를 **통째로** 끌어다 놓기
5. 아래 **Commit changes** 누르기

다 올리면 이렇게 보여야 합니다. `manifest.json` 이 닉네임 폴더 바로 안에 있어야 해요.

```
round1/
└── 내닉네임/
    ├── manifest.json
    ├── popup.html
    ├── popup.js
    ├── ...
    ├── README.md          ← 소개 글
    └── screenshot.png
```

**고쳐서 다시 올릴 때**도 같은 방법으로, 같은 닉네임 폴더에 다시 올리면 됩니다. 같은 이름의 파일은 새 내용으로 바뀌고, 마지막에 올린 것이 제출본이에요. git을 쓰는 사람은 내 닉네임 폴더만 고쳐서 `git push` 해도 됩니다.

- **내 폴더만** 올리고 고칩니다. 다른 사람 폴더는 건드리지 않아요.
- `[강사예시]` 폴더는 고치지 않습니다.

## 대시보드

올린 과제는 강사가 모아서 대시보드에 **갤러리**로 보여 줍니다. 카드 하나에 닉네임, 스크린샷, 확장 프로그램 이름과 설명, 이전 라운드보다 무엇이 바뀌었는지가 들어갑니다. 그래서 `screenshot.png` 가 있어야 카드에 내 화면이 보여요.

## 막힐 때

| 증상 | 해결 |
|---|---|
| Upload files 버튼이 없다 | 초대를 아직 수락하지 않았어요. 메일함 확인 |
| 파일이 `round1` 바로 아래에 흩어졌다 | 폴더 안 파일만 끌었어요. **닉네임 폴더째** 끌어다 놓기 |
| 닉네임 폴더 안에 폴더가 하나 더 생겼다 | 한 단계 위 폴더를 끌었어요. 닉네임 폴더 바로 안에 `manifest.json` 이 오게 다시 올리기 |
| Commit 할 때 오류 | 다른 사람과 동시에 올렸어요. 새로고침 후 다시 |
