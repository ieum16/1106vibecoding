# 강사 예시

수업에서 보여 주는 예시 확장 프로그램과 웹페이지입니다. 아래 안내에 따라 실행해 보세요. 수강생은 이 폴더를 고치지 않습니다.

| 폴더 | 내용 |
|---|---|
| [01_기본-todo](01_기본-todo) | 할 일 추가 · 완료 체크 · 삭제 · 남은 개수 |
| [02_메일-todo](02_메일-todo) | 지메일에서 메일을 열면 「+ 할 일에 추가」 버튼이 생겨서 메일 제목을 할 일로 넣어 줌 |
| [03_팀-소개-페이지](03_팀-소개-페이지) | 가상 브릿지팀 소개 웹페이지 · 로고 · 기획서(PRD) |

팀 소개 페이지: `03_팀-소개-페이지/index.html`을 브라우저로 열어 보세요. 기획서는 같은 폴더의 `prd.md`에 있습니다.

확장 프로그램 설치: 주소창에 `chrome://extensions` → 개발자 모드 켜기 → 「압축해제된 확장 프로그램 로드」 → 폴더 선택
