# 오늘 할 일 작성기

닉네임: `-panda`

## 한 줄 소개

오늘 할 일을 적고 완료한 일을 체크하며, 남은 일을 한눈에 확인하는 크롬 확장 프로그램입니다.

## 누구를 위해 만들었나요

아침에 할 일을 정리하고, 브라우저를 사용하는 동안 간편하게 확인하고 싶은 사람을 위해 만들었습니다.

## 주요 기능

- 할 일 추가, 완료 체크·해제, 삭제와 남은 개수 표시
- 빈칸·공백 입력 방지, 한글 입력 중 Enter 오작동 방지, 다시 열어도 유지되는 자동 저장
- 폭 360px의 한국어 화면, 큰 글씨와 오렌지 포인트, 전체·완료 개수 및 완료 진행 막대

## 강사 예시에서 바꾼 점

- 초록색 포인트를 오렌지로 바꾸고, 한국어 날짜와 요일을 표시했습니다.
- 남은 개수 외에 전체·완료 개수와 완료 진행 막대를 추가했습니다.
- 긴 할 일은 줄바꿈하고 목록 안에서 스크롤되도록 했으며, 한글 조합 중 Enter로 잘못 추가되는 것을 막았습니다.

## 써 보는 법

1. 크롬 주소창에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `round1/-panda` 폴더를 선택합니다.
3. 확장 프로그램 아이콘을 눌러 할 일을 입력하고, **추가** 또는 Enter로 등록합니다. 체크박스로 완료하고 휴지통 버튼으로 삭제합니다.

목록은 이 브라우저의 `chrome.storage.local`에 저장됩니다. 팝업이나 브라우저를 다시 열어도 유지되며, 날짜가 바뀌어도 자동으로 초기화하지 않습니다.

## 만들면서 배운 점

팝업을 닫아도 목록을 유지하려면 변경할 때마다 저장해야 합니다. 저장이 실패하면 화면에 안내하고, 빈 입력과 한글 입력 중 Enter도 별도로 처리해야 한다는 점을 확인했습니다.
