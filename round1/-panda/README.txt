1. 크롬 주소창에 chrome://extensions 를 입력합니다.
2. 오른쪽 위의 '개발자 모드'를 켭니다.
3. '압축해제된 확장 프로그램을 로드합니다'를 눌러 이 -panda 폴더를 선택합니다.

이름: 오늘 할 일 작성기
사용: 도구 모음의 퍼즐 아이콘에서 확장 프로그램을 고정한 뒤 아이콘을 클릭하세요.
할 일은 Enter 또는 '추가'로 등록하고, 체크로 완료 표시하고, 휴지통으로 삭제합니다.
목록은 chrome.storage.local에 자동 저장되며 팝업이나 크롬을 다시 열어도 유지됩니다.
매일 자동으로 초기화하지 않습니다. 확장 프로그램을 제거하면 저장된 목록도 삭제됩니다.
인터넷 연결이나 별도 설치 도구 없이 동작합니다.
