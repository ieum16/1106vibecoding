# 오늘 할 일 작성기

닉네임: **freeoing1** · 1라운드 과제

## 한 줄 소개

오늘 할 일을 추가하고 완료를 체크하며 남은 개수를 확인하는 크롬 확장 프로그램입니다.

## 누구를 위해 만들었나요

아침에 오늘 할 일을 적어 두고, 하루 동안 끝낸 일을 확인하고 싶은 사람을 위해 만들었습니다.

## 주요 기능

- 할 일 추가 및 삭제: 공백만 입력한 항목은 추가하지 않습니다.
- 완료 체크 및 해제: 완료 상태에 따라 남은 할 일 개수를 바로 표시합니다.
- 자동 저장: 팝업을 닫았다 다시 열어도 목록과 완료 상태가 유지됩니다.

## 화면

폭 360px, 큰 한국어 글씨, 파란색 포인트를 적용했습니다.

대표 화면 캡처(screenshot.png)는 아직 첨부하지 않았습니다.

## 강사 예시에서 바꾼 점

- 요청한 조건에 맞춰 별도로 제작한 버전입니다.
- 큰 글씨와 한국어 안내, 파란색 포인트를 적용했습니다.
- 저장 중 중복 입력을 막고 저장 실패 시 안내를 표시합니다.

## 써 보는 법

1. 저장소를 내려받아 압축을 푼 뒤 크롬 주소창에 `chrome://extensions`를 입력하고 개발자 모드를 켭니다.
2. '압축해제된 확장 프로그램을 로드합니다'를 눌러 `round1/freeoing1` 폴더를 선택합니다.
3. 확장 프로그램을 열어 할 일을 입력하고 '추가'를 누릅니다. 체크박스로 완료를 표시하고 '삭제'로 지웁니다.

## 다음에 붙이고 싶은 기능

- 아직 정하지 않았습니다.

## 만들면서 배운 점

할 일 목록뿐 아니라 완료 상태도 저장해야 다시 열었을 때 같은 화면을 복원할 수 있습니다.
빈칸 검사와 저장 실패 안내도 사용 흐름에 필요합니다.
