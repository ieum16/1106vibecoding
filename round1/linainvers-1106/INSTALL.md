# 한 주, 한 걸음

월–금 날짜별로 업무를 관리하는 Chrome 확장프로그램입니다. 로그인이나 서버, 인터넷 연결 없이 동작합니다.

## 설치하기

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. `manifest.json`이 들어 있는 `새로운확장프로그램` 폴더를 선택합니다. ZIP 파일을 받았다면 먼저 압축을 풉니다.
5. Chrome 오른쪽 위 퍼즐 아이콘에서 **한 주, 한 걸음**을 고정한 뒤 아이콘을 누릅니다.

## 사용하기

- 각 날짜의 입력란에 업무를 적고 Enter 또는 **추가**를 누릅니다.
- 체크박스로 완료를 표시합니다. 완료한 업무에는 취소선이 생깁니다.
- ☆를 누르면 중요 업무로 지정되어 주황색 배경과 ★로 표시됩니다.
- **수정**으로 내용을 바꾸고, ×로 삭제합니다. 삭제 전 확인창이 나옵니다.
- 화살표로 주를 이동하고 **이번 주**로 돌아옵니다.
- **중요 업무만**으로 중요한 업무를 모아 봅니다. 완료율은 필터와 관계없이 그 주의 근무일 업무 전체를 기준으로 합니다.
- **넓게 보기**에서 다섯 요일을 한눈에 볼 수 있습니다.
- **휴일 관리**에 날짜와 이름을 추가하면 해당 날짜가 숨겨집니다. **해제**하면 다시 표시됩니다. 기본 공휴일은 해제할 수 없습니다.
- 주말은 항상 제외됩니다. 휴일로 숨겨진 업무는 삭제되지 않고 보관됩니다.

## 저장과 개인정보

업무와 직접 등록한 휴일은 현재 Chrome 프로필의 확장프로그램 저장소(`chrome.storage.local`)에 자동 저장됩니다. 다른 컴퓨터와 동기화되지 않습니다. 외부 서버 전송, 웹페이지 접근, 방문 기록 수집을 하지 않습니다. 확장프로그램을 삭제하거나 프로필 데이터를 지우면 저장된 업무도 사라질 수 있습니다. 업무 입력 중인 초안은 **추가**를 눌러야 저장됩니다.

## 공휴일 적용 범위

- 2026년과 2027년 대한민국 공휴일 및 대체공휴일을 내장했습니다. 노동절·제헌절 및 2026년 전국동시지방선거일을 포함합니다.
- 자료 기준일: 2026-11-06. 이후 추가되는 임시공휴일과 회사 휴무일은 직접 등록하세요.
- 다른 연도도 주간 목록을 사용할 수 있지만 공휴일은 직접 등록해야 합니다. 해당 연도에는 안내문이 표시됩니다.
- 출처: [우주항공청 2026년 월력요항](https://www.kasa.go.kr/prog/plcyBrf/brief/kor/sub01_01_04/view.do?plcyBrfNo=202), [우주항공청 2027년 월력요항](https://www.kasa.go.kr/prog/plcyBrf/brief/kor/sub01_01_04/view.do?plcyBrfNo=431). 공공누리 제1유형 자료의 날짜 정보를 참고했으며 2027년 발표에 명시된 2026년 노동절·제헌절 추가 사항도 반영했습니다.

## 개발 및 검증

Manifest V3, HTML/CSS/JavaScript로 작성했습니다. 빌드 과정은 없습니다. 요청 권한은 `storage` 하나입니다. 파일을 수정한 경우 확장프로그램 관리 화면에서 새로고침한 뒤 팝업을 다시 여세요.

`node tests/smoke.mjs`로 로컬 Chrome 헤드리스 테스트를 실행할 수 있습니다. Node.js 22 이상과 기본 경로의 Windows Chrome이 필요합니다. 브라우저의 저장 API를 모의 구현하여 실제 화면에서 업무 CRUD, 자동 저장, 필터, 휴일 숨김/복원, 저장 오류를 확인합니다. 실제 확장프로그램 설치 자체는 Chrome에서 별도로 확인해야 합니다.
