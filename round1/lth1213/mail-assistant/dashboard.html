처음 시작하시나요?

  1. 샘플로 체험을 누르면 실제 메일 없이 분류와 복구를 확인할 수 있습니다.
  2. Microsoft Entra 관리 센터 → 앱 등록 → 새 등록에서 사용 계정 유형을 선택하세요.
  3. 인증 → 플랫폼 추가 → 단일 페이지 애플리케이션(SPA)에 위 리디렉션 URI를 그대로 등록하세요.
  4. Microsoft Graph의 위임된 권한에 User.Read, Mail.ReadWrite를 추가하세요. 회사 계정은 관리자 승인이 필요할 수 있습니다.
  5. 애플리케이션 ID 저장 → Outlook 연결 → 규칙 저장 → 미리보기 → 분류 실행 순서로 시작하세요.
  6. 스팸 규칙은 스팸 → 정크 메일을 선택하고 키워드를 입력하세요. 저장 시 자동 실행이 켜집니다.

Microsoft 365 / Outlook.com의 로그인한 계정 본인 사서함을 지원합니다. 온프레미스 Exchange, 공유 사서함과 로컬 PST는 지원하지 않습니다. 정크 폴더 이동은 Microsoft 스팸 필터 학습·신고와 별개입니다.

메일 본문은 규칙 검사 중에만 사용합니다. 규칙, 제목, 보낸 사람, 이동 기록은 이 브라우저에 저장하며 외부 분석 서비스로 전송하지 않습니다. 연결 토큰은 브라우저 세션에만 보관하므로 브라우저 재시작 후 다시 연결하세요.
