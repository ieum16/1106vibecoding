# 지원노트 · 채용 지원 도우미

채용 공고와 내 이력서를 비교하고, 근거를 확인하면서 맞춤 이력서와 자기소개서를 작성하는 개인용 Chrome 확장프로그램입니다.

## 처음 실행하기

1. Node.js 22 이상을 설치합니다. 
2. 이 프로젝트 폴더에서 `.env.example`을 복사해 `.env`를 만듭니다.
3. `.env`에 `OPENAI_API_KEY`와 본인 계정에서 사용 가능한 `OPENAI_MODEL`을 입력합니다. 모델은 Responses API의 Structured Outputs(JSON Schema)를 지원해야 합니다. API 사용 비용이 발생하며 이 앱의 채팅 연결과는 별도입니다. 키를 채팅에 붙여넣지 마세요.
4. 터미널에서 이 제출 폴더로 이동한 후 `npm install` 및 `npm start`를 실행합니다.
5. 표시되는 **연결 토큰**을 복사합니다. 서버가 실행되는 동안 터미널을 열어둡니다.
6. Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드 → 압축해제된 확장 프로그램을 로드**를 선택합니다.
7. **manifest.json이 들어 있는 이 제출 폴더**를 선택합니다.
8. 확장 아이콘을 고정하고 누릅니다. **연결 설정**에 토큰을 입력하고 자료 전송 동의를 확인한 뒤 저장하고 연결 확인을 누릅니다.
9. **이력서와 문체**에서 PDF, DOCX, TXT, MD 파일을 읽거나 직접 붙여넣고 추출 내용을 확인해 저장합니다.
10. 채용 공고를 연 뒤 확장 아이콘 → **현재 탭 읽기** → 본문 확인 → **공고와 이력서 분석**을 누릅니다.

API 키 없이도 **체험용 예시 보기**로 화면과 수정본 편집·복사·다운로드를 확인할 수 있습니다. 체험 결과는 미리 작성한 샘플이며 실제 분석이 아닙니다.

## 자동 분석

공고 탭의 패널에서 **이 사이트 자동 분석 켜기**를 눌러 해당 사이트만 권한을 부여합니다. 저장한 이력서와 전송 동의가 있어야 켤 수 있습니다. 이후 해당 사이트에서 채용 관련 본문이 있는 페이지 로드가 완료되면 분석하고 확장 아이콘에 결과 상태를 표시합니다. 사이드 패널은 브라우저 제약상 새 페이지마다 자동으로 튀어나오지 않습니다. 아이콘을 눌러 결과를 확인하세요.

공고 목록, 늦게 로딩되는 페이지, 로그인·iframe·이미지 공고 및 페이지 새로고침 없이 바뀌는 일부 사이트에서는 잘못 읽거나 자동 분석을 놓칠 수 있습니다. 이때 **현재 탭 읽기** 또는 직접 붙여넣기를 사용하세요. 사이트별 추출 정확도는 실제 사용하는 공고로 추가 검증이 필요합니다. 자동 분석은 **연결 설정**에서 사이트별로 끌 수 있습니다.

## 결과 해석과 수정본

- 직무 적합도는 필수 조건 2배, 우대 조건 1배 가중치입니다. 충족은 1, 부분 충족은 0.5, 미충족·확인 필요는 0을 곱한 비율입니다. 실제 합격 확률은 아닙니다. 문서에 근거가 없으면 경험 자체가 없다는 뜻도 아닙니다.
- AI가 분류한 요구사항을 바탕으로 계산하므로 분류와 해석이 틀릴 수 있습니다. 공고와 이력서 인용을 함께 검토하세요.
- 서버는 인용이 원문에 존재하는지 검사합니다. 이 검사가 인용의 의미나 모든 생성 문장의 사실성을 보장하지는 않습니다.
- 원본 이력서는 보존됩니다. 수정본에서 `[확인 필요: ...]`를 확인하고 직접 편집한 뒤 **수정본 저장**을 누르세요. 이력서와 자소서는 TXT로 복사·다운로드합니다. 원본 PDF·Word 서식 수정이나 DOCX 출력은 현재 제공하지 않습니다.
- 스캔 PDF OCR, HWP, 자동 지원서 제출, AI 탐지 결과 보장은 제공하지 않습니다.
- 자소서 공백 포함 글자 수와 초과 상태를 표시합니다. 제출 사이트의 글자 수 계산 방식과 다를 수 있습니다.

## 자료와 API 키

- 파일의 텍스트 추출은 브라우저에서 실행합니다. 원본 파일을 서버로 업로드하지 않습니다. PDF는 최대 60쪽, 파일은 최대 10MB, 각 입력 텍스트는 최대 60,000자입니다.
- 이력서, 문체, 공고와 최근 분석 10건(분석 당시 입력과 수정본 포함)은 Chrome 로컬 저장소에 저장됩니다. 암호화된 비밀 보관함은 아닙니다. 공용 PC에서는 사용 후 **모든 로컬 자료 삭제**를 누르세요.
- 분석 시 이력서·문체·공고 본문·자소서 문항·글자 수를 로컬 서버와 OpenAI에 전송합니다. 전송 전 본문에서 불필요한 연락처 등은 직접 지울 수 있습니다.
- 서버는 `127.0.0.1:4317`에만 바인딩하고 토큰으로 요청을 인증합니다. API 키는 `.env`, 연결 토큰은 `.local-token`에 보관하며 ZIP에는 포함하지 않습니다. 이 두 파일을 공유하지 마세요.
- 서버는 입력과 결과를 디스크나 콘솔에 기록하지 않습니다. OpenAI 요청에는 `store:false`를 사용합니다. 이는 모든 제공자 로그가 즉시 삭제된다는 뜻이 아니며 제공자의 데이터 정책이 적용됩니다.
- 초기 버전은 개인 컴퓨터용입니다. 공개 서버 배포나 Chrome 웹스토어 배포는 포함하지 않습니다.

## 개발 및 검증

```sh
npm install
npm run build
npm test
npm start
```

`src/app.js`는 화면 로직, `background.js`는 공고 추출과 자동 분석, `server/index.mjs`는 AI 연결, `src/contracts.js`는 스키마와 점수 규칙입니다. 소스 수정 후 빌드하고 Chrome 확장 관리에서 새로고침하세요. Node 서버를 중지하려면 Ctrl+C를 누릅니다.

공식 참고: [Chrome Side Panel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel), [선택 권한](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions), [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses).
