# 교육 시간표

## 한 줄 소개

교육 일정과 남은 시간, 할 일와 쉬는 시간 게임을 한곳에 모은 크롬 새 탭 확장 프로그램입니다.

## 누구를 위해 만들었나요

수업과 휴식 시간을 확인하고 배운 내용을 빠르게 할 일하고 싶은 교육생을 위해 만들었습니다.

## 주요 기능

- 날짜별 수업 등록·수정·삭제, 교육/휴식 시간 자동 분할, 시작·종료 시간과 초 단위 남은 시간 표시
- 팝업과 새 탭에서 공유하는 목록형 할 일, 밝은 디자인과 내장 Pretendard 폰트
- 쉬는 시간에 즐기는 벽돌 깨기·테트리스·지뢰찾기 탭

## 화면

대표 화면 캡처는 아직 첨부하지 않았습니다. 확장 버튼을 누르면 팝업을, 새 탭을 열면 전체 대시보드를 볼 수 있습니다.

## 강사 예시에서 바꾼 점

- 교육 시간표와 카운트다운을 중심으로 화면을 구성했습니다.
- 교육 시간과 휴식 시간을 입력하면 전체 교육 시간을 세부 구간으로 나누도록 했습니다.
- 팝업에 오늘의 전체 시작·종료 시간과 남은 시간, 최신 할 일을 간결하게 배치했습니다.
- 목록형 할 일, 세 가지 미니 게임, 초 단위 시계와 개인 인사말을 추가했습니다.

## 써 보는 법

1. 저장소를 내려받고 Chrome의 chrome://extensions 에서 개발자 모드를 켠 뒤, '압축해제된 확장 프로그램을 로드합니다'로 round1/강윤기 폴더를 선택합니다.
2. 새 탭에서 날짜·수업명·시작·종료 시간을 등록합니다. 자동 분할을 선택하면 교육/휴식 길이를 분 단위로 지정할 수 있습니다.
3. 확장 버튼으로 교육 시간과 최신 할 일을 확인합니다. 전체 대시보드에서는 할 일 관리와 미니 게임도 이용할 수 있습니다.

시간표·할 일·설정은 브라우저 내부에 저장됩니다. Chrome 계정 자동 이름은 이메일의 @ 앞부분을 사용하며 설정에서 수동 이름으로 바꿀 수 있습니다. 이메일은 저장하지 않습니다. 구글 캘린더 연동과 온라인 멀티플레이는 포함하지 않았습니다.

## 다음에 붙이고 싶은 기능

- 시간표 내보내기·가져오기와 수업 시작 알림
- 연결 정보를 교환해 함께 즐기는 테트리스 멀티플레이

## 만들면서 배운 점

팝업과 새 탭이 같은 저장 데이터를 공유하도록 구성하고, 교육 시간 분할과 남은 시간 계산을 별도 로직으로 나누었습니다. 제한된 팝업 높이에 맞춰 할 일 개수를 조절하고 작은 아이콘의 가독성을 개선했습니다.
