교육 시간표

설치 및 업데이트
1. 크롬 주소창에 chrome://extensions 를 입력합니다.
2. 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드합니다'를 선택합니다.
3. 내려받은 저장소의 round1\강윤기 폴더를 선택합니다.
4. 이미 설치했다면 교육 시간표 카드의 새로고침을 누르고 기존 대시보드 탭도 새로고침합니다.

사용 방법
- 확장 버튼을 누르면 할 일 입력칸이 바로 표시됩니다.
- 할 일은 입력 후 할 일 추가 버튼으로 목록에 저장합니다. 각 항목을 수정·삭제할 수 있습니다.
- 기존 할 일은 첫 항목으로 옮겨집니다. 팝업과 대시보드가 같은 목록을 사용합니다.
- 전체 대시보드에서 교육 날짜, 수업명, 시작·종료 시간을 입력할 수 있습니다.
- 수업 수정·삭제, 시간순 정렬, 시작 시간·종료 시간, 진행 중 수업의 초 단위 남은 시간·진행률을 지원합니다.
- 같은 날짜에 시간이 겹치거나 종료 시간이 시작 시간보다 이른 수업은 등록되지 않습니다.
- 교육 시간표는 컴퓨터의 현지 시간 기준으로 동작하며 날짜별로 저장됩니다.

데이터와 권한
- storage, identity, identity.email 권한을 사용합니다.
- 할 일·교육 시간표·개인 설정은 이 브라우저에 저장됩니다.
- 크롬 기본 로그인 계정의 이메일 아이디를 읽어 인사말에 표시합니다. 외부 서버 요청은 없습니다.
- 실제 구글 프로필 이름은 이 API에서 제공되지 않으며, 이메일과 계정 ID를 저장하지 않습니다.
- 설정에서 자동 사용을 끄면 이름을 직접 입력할 수 있습니다.
- 로그인하지 않았거나 권한을 사용할 수 없으면 기존 이름 또는 교육생으로 표시합니다.
- 확장 프로그램을 제거하면 저장된 데이터도 삭제됩니다.
- 일반 브라우저 미리보기의 데이터는 설치된 확장 프로그램 데이터와 별개입니다.

디자인
Pretendard 폰트를 내장합니다. 라이선스: fonts/LICENSE.txt

세부 교육 시간 자동 분할
1. 교육 날짜·수업명·전체 시작 시간·종료 시간을 입력합니다.
2. 교육·휴식 시간으로 자동 분할을 체크합니다.
3. 교육 시간과 휴식 시간을 분 단위로 입력합니다. 기본값은 50분/10분입니다.
4. 미리보기 확인 후 분할 시간표 저장을 누릅니다.
5. 기존 수업을 나누려면 해당 항목의 수정을 누른 후 자동 분할을 선택합니다.
선택한 수업만 분할 항목으로 교체하며 다른 시간표는 유지합니다.
마지막 구간은 전체 종료 시간에 맞추며, 마지막 휴식도 포함합니다.
휴식 0분은 쉬는 시간 없이 교육 구간만 나눕니다.
생성한 교육·휴식 항목은 각각 수정·삭제할 수 있습니다.

미니 게임
할 일 아래에서 벽돌 깨기·테트리스·지뢰찾기 탭을 선택할 수 있습니다.
탭을 바꿔도 같은 페이지에서는 상태가 유지됩니다. 페이지를 새로고침하면 게임은 초기화됩니다.
벽돌 깨기와 테트리스는 다른 게임 탭이나 다른 창으로 이동할 때 일시정지됩니다.
- 벽돌 깨기: 마우스·터치·좌우 방향키 이동, 스페이스 시작/정지
- 테트리스: 좌우 방향키 이동, 위 회전, 아래 내리기, 스페이스 즉시 내리기, P 정지
  화면의 조작 버튼도 사용할 수 있습니다.
- 지뢰찾기: 9×9 칸, 지뢰 10개. 클릭으로 열고 오른쪽 클릭 또는 F로 깃발 표시
  첫 클릭 주변은 안전합니다. 터치에서는 깃발 모드를 사용하세요.
