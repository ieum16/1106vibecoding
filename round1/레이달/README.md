# 오늘 할 일 작성기

## 한 줄 소개

할 일을 적으면 계수정 선생님이 읽어 주고, 끝내면 함께 축하하는 오늘 할 일 메모장입니다.

## 누구를 위해 만들었나요

아침에 오늘 할 일을 몇 개 적어 두고, 하나 끝낼 때마다 응원을 받고 싶은 사람.

## 주요 기능

- 할 일을 적으면 말풍선이 한 글자씩 읽어 줍니다.
- 확인을 누르면 캐릭터가 점프하고, 항목에 참 잘했어요가 찍힙니다.
- 남은 할 일 개수를 세어 다음 할 일을 이어서 알려 줍니다.

## 강사 예시에서 바꾼 점

- 초록색 메모장 화면을 계수정 선생님 웹툰 화면으로 바꿨습니다.
- 할 일을 말풍선으로 읽어 주고, 끝내면 점프와 참 잘했어요 도장이 나오게 했습니다.
- 말풍선에 「저는 실패하지 않습니다」를 넣었습니다.

## 써 보는 법

1. 크롬에서 이 폴더를 압축해제된 확장 프로그램으로 불러옵니다.
2. 툴바의 오늘 할 일 작성기 아이콘을 눌러 팝업을 엽니다.
3. 할 일을 적고 추가한 뒤, 끝내면 확인을 누릅니다.

## 다음에 붙이고 싶은 기능

- 할 일마다 마감 시간을 붙이고 싶습니다.

## 만들면서 배운 점

팝업과 크게 보기는 같은 화면인데, 작은 팝업에서도 캐릭터와 목록이 같이 보이게 맞추는 게 포인트였습니다.
