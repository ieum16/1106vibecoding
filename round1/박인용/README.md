# 오늘 할 일 작성기

닉네임: 박인용

## 한 줄 소개

오늘 할 일을 적고, 완료를 체크하며 남은 일을 확인하는 크롬 확장 프로그램입니다.

## 누구를 위해 만들었나요

아침에 오늘 할 일을 정리하고 브라우저에서 간편하게 확인하고 싶은 사람을 위해 만들었습니다.

## 주요 기능

- 할 일 추가와 삭제, 빈칸 및 공백만 있는 입력 방지
- 완료 체크와 남은 할 일 개수 표시
- 목록과 완료 상태 자동 저장: 팝업이나 브라우저를 다시 열어도 유지

## 화면

폭 360px, 큰 한국어 글씨와 파란색 포인트를 적용했습니다.

![오늘 할 일 작성기를 처음 열었을 때 화면](screenshot.png)

## 강사 예시에서 바꾼 점

강사 예시를 직접 수정한 버전이 아니라, 요청한 기능을 바탕으로 새로 만든 확장 프로그램입니다.

- 폭 360px의 한국어 화면에 큰 글씨와 파란색 포인트 적용
- 빈칸 입력 방지, 저장 실패 안내, 남은 개수 표시 구현

## 써 보는 법

1. 크롬 주소창에 `chrome://extensions`를 입력하고 개발자 모드를 켠 뒤, **압축해제된 확장 프로그램을 로드합니다**에서 이 `박인용` 폴더를 선택합니다.
2. **오늘 할 일 작성기** 아이콘을 클릭하고 할 일을 입력한 뒤 **추가**를 누릅니다.
3. 끝낸 일은 체크하고 필요 없는 일은 **삭제**를 누릅니다. 창을 다시 열면 저장된 목록이 표시됩니다.

## 만들면서 배운 점

구현에서 사용한 방법: `chrome.storage.local`에 목록과 완료 상태를 저장하고, 입력값의 앞뒤 공백을 제거해 공백만 있는 할 일의 추가를 막았습니다.
