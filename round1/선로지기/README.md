# 오늘 할 일 작성기 · 날씨 한 줄

## 한 줄 소개

오늘 할 일을 적고 끝내면 체크하는 작은 메모장에, 서울의 오늘 날씨를 한 줄로 붙였어요.

## 누구를 위해 만들었나요

출근해서 오늘 할 일을 3~5개 적어 두고, 나가기 전에 날씨도 같이 확인하고 싶은 사람

## 주요 기능

- 할 일 추가 · 완료 체크 · 삭제, 남은 할 일 개수 표시
- 같은 할 일을 두 번 넣으면 "이미 목록에 있는 할 일이에요"라고 알려 주고 추가하지 않음
- 할 일 목록 위에 서울의 오늘 날씨와 기온 표시 (실패하면 "날씨를 가져오지 못했어요")

## 강사 예시에서 바꾼 점

- 같은 할 일 두 번 넣기를 막았어요 (띄어쓰기·영문 대소문자만 다른 것도 같은 할 일로 봐요)
- 아주 긴 문장이 한 줄로 삐져나가던 것을 줄바꿈되게 고쳤어요
- 추가 버튼을 빠르게 연타해도 한 번만 들어가게 했어요
- 전체 색을 연두에서 파랑(#2F63E0) 계열로 바꿨어요
- Open-Meteo(가입·키 없이 쓰는 무료 날씨 API)로 서울 오늘 날씨를 붙였어요

## 써 보는 법

1. 크롬 주소창에 `chrome://extensions` → 개발자 모드 켜기 → 「압축해제된 확장 프로그램 로드」 → 이 폴더 선택
2. 퍼즐 아이콘에서 핀을 눌러 고정한 뒤 아이콘을 눌러 열기
3. 할 일을 적고 「추가」, 끝난 일은 체크, 필요 없으면 × 로 삭제

## 다음에 붙이고 싶은 기능

- 다음 공휴일까지 D-day 표시
- 완료한 일과 남은 일을 업무 보고 문장으로 복사하는 버튼

## 만들면서 배운 점

"안 돼요, 고쳐 줘" 대신 「무엇을 했더니 · 기대한 것 · 실제 결과」 세 줄로 말하니 딱 그 부분만 고쳐졌어요. 이것저것 눌러 보기에서 긴 문장이 화면 밖으로 삐져나가는 문제를 찾은 게 가장 쓸모 있었어요.
