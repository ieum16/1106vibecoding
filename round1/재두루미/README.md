# 재두루미의 오늘 할 일

## 한 줄 소개

오늘 할 일을 관리하고 수원의 현재 기온과 날씨를 함께 확인하는 크롬 확장 프로그램입니다.

## 누구를 위해 만들었나요

브라우저에서 오늘 할 일을 간단하게 적고 확인하고 싶은 사람을 위해 만들었습니다.

## 주요 기능

- 할 일 추가, 완료 표시, 삭제와 남은 할 일 개수 표시
- 브라우저에 목록을 저장하여 다시 열어도 유지
- Open-Meteo API로 수원 현재 기온과 날씨 표시, 로딩 및 실패 안내

## 강사 예시에서 바꾼 점

- 제목을 ‘재두루미의 오늘 할 일’로 변경했습니다.
- 추가 버튼을 하늘색으로 바꿨습니다.
- TODAY는 13px로 유지하고 제목은 15px, 나머지 글자는 12px로 조정했습니다.
- 목록 위에 수원 날씨를 추가했습니다. 불러오는 동안 ‘불러오는 중…’, 실패하면 ‘날씨를 가져오지 못했어요’를 표시합니다.
- 날씨 조회가 10초를 넘으면 실패로 처리합니다.

## 써 보는 법

1. 이 저장소를 내려받아 압축을 풉니다.
2. 크롬의 `chrome://extensions`에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’를 선택합니다.
3. `round1/재두루미` 폴더를 선택하고 확장 프로그램 아이콘을 눌러 사용합니다.

날씨는 인터넷 연결이 필요하며 API 키는 필요하지 않습니다. 날씨 데이터 제공: [Open-Meteo](https://open-meteo.com/).
