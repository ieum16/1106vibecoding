# 오늘 할 일 작성기

## 한 줄 소개
오늘 할 일을 추가하고 완료 여부를 관리하는 기본형 크롬 확장 프로그램입니다.

## 누구를 위해 만들었나요
오늘 해야 할 일을 간단히 적고 완료 여부를 확인하고 싶은 사람을 위한 도구입니다.

## 주요 기능
- 할 일 추가 및 삭제
- 체크박스로 완료 표시 및 남은 할 일 개수 확인
- Chrome 내부 저장소에 목록 저장

## 화면
대표 스크린샷은 아직 첨부하지 않았습니다.

## 강사 예시에서 바꾼 점
- 이번 제출은 기본형 버전입니다. 별도의 기능 변경은 포함하지 않았습니다.

## 써 보는 법
1. Chrome의 `chrome://extensions`에서 개발자 모드를 켭니다.
2. 압축해제된 확장 프로그램 로드에서 이 폴더를 선택합니다.
3. 확장 프로그램을 열어 할 일을 입력하고 추가합니다. 완료하면 체크하고, 삭제하려면 × 버튼을 누릅니다.

## 다음에 붙이고 싶은 기능
- 추후 결정 예정입니다.
