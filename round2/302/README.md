# HRM 팀 홈페이지

## 한 줄 소개

HRM은 채용과 교육을 비롯한 인사 업무를 맡고, 새로운 동료의 시작과 구성원의 성장을 돕는 팀입니다.

## 누구를 위해 만들었나요

신규 입사자와 채용 지원자가 가상의 IT 회사 하늘테크와 HRM 팀이 하는 일을 이해할 수 있도록 만들었습니다.

## 페이지 구성

- 회사 소개
- HRM 소개
- 하는 일: 채용, 신규 입사자 지원, 교육, 인사평가, 복리후생, 인사제도
- 채용·교육 안내
- 문의

PRD로 페이지 내용과 순서를 정하고, 스타일 가이드에 맞춰 반응형 HTML을 만들었습니다. GitHub에 올린 페이지가 Vercel에서 열리는 것도 확인했습니다.

> 이 페이지의 회사 이름과 문의처는 연습용 가상 정보입니다.
