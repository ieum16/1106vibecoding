# HRM 팀 홈페이지 제작 계획서

## 1. 만들 것

- `prd.md`와 `style-guide.md`를 바탕으로 가상 IT 회사와 HRM 팀을 소개하는 한 장짜리 `index.html`
- 대상: 신규 입사자와 채용 지원자
- 사용자가 제공한 Forest and Sage 스타일을 적용해 홈페이지를 제작한다.

## 2. 파일 구조

```text
team-page/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ style-guide.md
├─ index.html          ← 제작 승인 후 만들 파일
└─ images/
   ├─ logo.png         ← 선택: 없으면 HRM 임시 로고
   └─ reference.png    ← 선택: 현재 없음
```

## 3. 준비물 체크

| 준비물 | 상태 | 없을 때 |
|---|---|---|
| 로고 `images/logo.png` | 없음 | HRM 글자 임시 로고 사용. 나중에 이미지로 교체 가능 |
| 참고 이미지 `images/reference.png` | 없음 | `style-guide.md`의 색·서체·질감·움직임을 따름 |
| 회사 소개 | 가상 회사 “하늘테크”로 초안 작성 (가정) | 제작 전에 이름을 바꿀 수 있음 |
| 문의 채널 · 이메일 | 예시 값만 있음 | `#hrm-문의`, `team@example.com`으로 표시하고 예시임을 명시 |

## 4. 만드는 순서

| 단계 | 할 일 | 확인할 것 |
|---|---|---|
| 1 | 고정 헤더, 회사·팀 소개, 업무, 채용·교육, 문의, 푸터 구성 | 메뉴가 섹션으로 이동하는지 |
| 2 | Forest and Sage 색상, Anton·Inter, 둥근 모서리, 노이즈 질감 적용 | 스타일 가이드와 맞는지 |
| 3 | 회사와 HRM 소개 작성 | 가상 회사임이 분명하고 팀 역할이 한눈에 보이는지 |
| 4 | 업무 카드 6개 작성 | 채용·신규 입사자 지원·교육·인사평가·복리후생·인사제도가 모두 있는지 |
| 5 | 채용·교육 안내와 “준비 중” 카드 작성 | 미정인 세부 일정이나 공고를 만들어 내지 않았는지 |
| 6 | 문의 섹션 작성 | 채널·이메일이 예시로 표시되는지 |
| 7 | 리빌·부유 애니메이션과 움직임 줄이기 설정 적용 | 정보가 애니메이션 없이도 보이는지 |
| 8 | 휴대폰 화면과 햄버거 메뉴 구현 | 375px에서 가로 스크롤 없이 사용할 수 있는지 |
| 9 | 최종 점검 | PRD의 완료 기준을 충족하는지 |

## 5. 섹션별 구현 메모

| 섹션 | 레이아웃 | 데스크톱 → 휴대폰 |
|---|---|---|
| 헤더 | HRM 임시 로고 왼쪽, 메뉴 오른쪽, 위에 고정 | 640px 아래에서 햄버거 메뉴 |
| 회사·팀 소개 | 소개 문구와 주요 버튼, 시각적 강조 요소 | 위아래로 쌓기 |
| 업무 카드 | 6개를 3열 그리드로 배치 | 태블릿 2열 → 휴대폰 1열 |
| 채용·교육 | 소개 카드 2개와 준비 중 표시 | 1열로 쌓기 |
| 문의 | Forest 배경과 Cream 글자, 예시 연락처 | 1열로 쌓기 |

## 6. 확인 방법

- 브라우저에서 `index.html`을 열고 메뉴와 버튼을 눌러 봅니다.
- 화면 너비를 375px로 줄여 가로 스크롤과 메뉴 동작을 확인합니다.
- PRD 12번의 완료 기준을 하나씩 확인합니다.

## 7. 만든 뒤 고치기 예시

- “인사제도 카드 설명을 더 구체적으로 바꿔 줘.”
- “Sage 보조 색을 더 밝게 바꿔 줘.”
- “채용 절차 안내를 추가해 줘.”
