# HRM 홈페이지 스타일 가이드 — Forest and Sage

사용자가 제공한 스타일 명세를 HRM 소개 페이지에 적용한 기준이다. 회사와 연락처는 연습용 가상 정보다.

## 색상

| 이름 | 색상 | 사용처 |
|---|---|---|
| Forest | `#01472e` | 헤더, 큰 제목, 진한 배경, 주요 버튼 |
| Sage | `#ccd5ae` | 보조 패널과 장식 |
| Olive | `#e9edc9` | 밝은 카드와 구획 |
| Cream | `#fefae0` | 기본 배경과 진한 배경 위 글자 |
| Moss | `#a3b18a` | 강조선과 작은 장식 |

## 글꼴

- 큰 영문 전시 제목: **Anton**. 첫 화면의 `PEOPLE`을 최대 23vw, 줄 간격 0.75, 자간 -0.05em으로 표현한다. 내용이 잘리지 않도록 작은 화면에서는 크기를 제한한다.
- 섹션 영문 제목: Anton, 최대 15vw. 한글 섹션 설명은 읽기 쉬운 크기로 따로 배치한다.
- 본문과 기능 요소: **Inter** 400·700. 한글은 시스템 한글 글꼴로 대체한다.
- 라벨과 버튼: 영문 대문자, 자간 0.2em~0.4em. 한글 문장에는 과도한 자간을 주지 않는다.

## 질감 · 형태

- 전체 뷰포트에 `pointer-events: none`인 고정 SVG fractal noise를 불투명도 0.04로 얹는다.
- 큰 영역 모서리는 `5rem`, 카드와 이미지는 `2.5rem`. 작은 화면에서는 공간에 맞춰 축소한다.
- 떠 있는 요소 그림자는 `rgba(1, 71, 46, 0.2)`를 사용해 부드럽고 깊게 표현한다.

## 움직임

- 화면 진입 요소는 `translateY(100px)`·`opacity: 0`에서 시작해 제자리·`opacity: 1`로 이동한다.
- 시간은 1.2초, 곡선은 `cubic-bezier(0.16, 1, 0.3, 1)`이다.
- 전경의 장식 요소만 20px 위로 떠오르고 5도 회전하는 부유 애니메이션을 사용한다.
- `prefers-reduced-motion: reduce`에서는 애니메이션과 부드러운 스크롤을 끈다.
- JavaScript를 사용할 수 없어도 내용이 보이도록 리빌의 초기 숨김은 스크립트 활성화 후에만 적용한다.

## HRM 페이지에 맞춘 사용법

- 강한 영문 제목으로 첫인상을 만들되, 신규 입사자와 지원자에게 필요한 한글 설명을 바로 이어서 제공한다.
- 카드 여섯 장은 장식보다 채용·교육·평가·복리후생 등 실제 업무 설명이 먼저 읽히게 한다.
- 미정인 채용·교육 일정은 점선 테두리와 “준비 중” 표시로 구분한다.
- 예시 문의처는 실제 연락처처럼 오인되지 않게 “예시”를 명시한다.
