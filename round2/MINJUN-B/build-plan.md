# 인사이트랩 홈페이지 제작 계획서

## 파일
- index.html: HTML·CSS·JS를 모두 포함한 홈페이지
- prd.md: 현재 대화에서 확정한 요구사항
- logo-prompt.md: 추후 로고를 만들 때 사용할 프롬프트
- images/: 기존 자료는 보존하되 다른 팀의 로고는 사용하지 않습니다.

## 준비물
로고, 프로젝트 이미지, 리뉴얼 상세, 주요 결과, 결과물 링크는 [준비 필요]입니다. 로고는 임시 글자 로고를 사용하고 나머지 콘텐츠는 [준비 필요]로 표시합니다.

## 구현 순서
1. 소개·프로젝트·푸터와 이동 메뉴를 구성합니다.
2. 남색·흰색 스타일과 글꼴·여백·버튼 규칙을 적용합니다.
3. 프로젝트 하나와 미정 정보 표시를 넣습니다.
4. 640px 이하에서 모바일 메뉴와 단일 열 구성을 적용합니다.
5. 메뉴, 키보드, 여러 화면 폭의 가로 넘침과 JS 오류를 확인합니다.

## 수정 원칙
사용자가 지정한 부분만 수정합니다. 배포는 GitHub·Vercel 대상으로 별도 진행합니다.
