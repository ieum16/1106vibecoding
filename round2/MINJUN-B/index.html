05 프로젝트

아래 5개 프로젝트는 모두 학습용 가상 사례입니다. 이미지와 리뉴얼 제안은 콘셉트 예시이며, 실제 고객사 작업이나 측정된 성과가 아닙니다.

PROJECT 01 / 생활용품 브랜드 · 가상 프로젝트

회사 홈페이지 리뉴얼

모아리빙

가상의 생활용품 브랜드 모아리빙의 홈페이지 자료를 살펴보고, 방문자가 브랜드와 제품을 쉽게 이해하도록 리뉴얼 방향을 정리했습니다.

기획 배경
회사 소개와 제품 정보가 여러 메뉴에 흩어져 있고, 휴대폰에서는 글자가 작아 핵심 정보를 찾기 어려운 상황을 설정했습니다.
메뉴 정리
메뉴를 브랜드 소개 · 제품 · 소식으로 묶고, 첫 화면에서 주요 제품으로 바로 이동하도록 구성했습니다.
콘텐츠 개선
긴 회사 소개를 줄이고, 제품마다 용도·소재·관리 방법을 같은 순서로 정리했습니다.
모바일 개선
제품 카드를 한 줄에 하나씩 배치하고, 글자와 버튼을 키워 읽고 누르기 쉽게 설계했습니다.
제안 결과물
메뉴 구성안, 첫 화면 배치안, 제품 소개 문구를 담은 가상의 리뉴얼 제안서입니다.

PROJECT 02 / 뷰티 · 스킨케어 · 가상 프로젝트

스킨케어 브랜드 홈페이지 리뉴얼

온리프

가상의 식물성 스킨케어 브랜드 온리프가 제품의 성분과 사용 방법을 명확하게 전달하도록 화면과 문구를 다시 구성했습니다.

기획 배경
감성 이미지에 비해 성분과 사용 순서 안내가 부족한 상황을 설정했습니다.
개선 방향
제품별 핵심 성분·사용 방법·자주 묻는 질문을 같은 형식으로 정리하고, 작은 화면에서도 읽기 쉬운 제품 카드를 제안했습니다.
제안 결과물
제품 소개 화면 구성안, 성분 안내 카드, 사용 순서 콘텐츠 예시입니다.

PROJECT 03 / 식음료 · 커피 · 가상 프로젝트

로스터리 홈페이지 리뉴얼

그레인 커피

가상의 로스터리 그레인 커피를 처음 방문하는 사람도 원두의 맛과 매장 분위기를 쉽게 살펴볼 수 있도록 소개 페이지를 기획했습니다.

기획 배경
원두마다 설명 방식이 달라 취향에 맞는 커피를 고르기 어려운 상황을 설정했습니다.
개선 방향
원두 정보를 산미·고소함·추천 추출법으로 통일하고, 브랜드 이야기·원두 소개·매장 안내 순서로 내용을 정리했습니다.
제안 결과물
원두 소개 카드, 매장 안내 배치안, 브랜드 스토리 문구 예시입니다.

PROJECT 04 / 건축 · 공간 디자인 · 가상 프로젝트

건축 스튜디오 홈페이지 리뉴얼

오르빗 스튜디오

가상의 건축 스튜디오 오르빗의 공간 사진과 설계 의도가 함께 전달되도록 프로젝트 중심의 포트폴리오를 제안했습니다.

기획 배경
사진은 많지만 공간의 용도와 설계 의도를 파악하기 어려운 상황을 설정했습니다.
개선 방향
프로젝트를 주거·상업·공공 공간으로 나누고, 대표 사진과 함께 공간의 목적·설계 아이디어를 짧게 배치했습니다.
제안 결과물
프로젝트 목록 구성안, 사진 배치 규칙, 공간 소개 문구 예시입니다.

업무 도구 소개 홈페이지 리뉴얼

플로우워크

가상의 협업 도구 플로우워크의 기능 나열을 줄이고, 팀이 어떤 문제를 해결할 수 있는지 이해하기 쉬운 소개 화면을 기획했습니다.

기획 배경
기능 이름과 전문 용어가 많아 도구의 쓰임을 이해하기 어려운 상황을 설정했습니다.
개선 방향
할 일 공유·진행 상황 확인·기록 모아보기의 세 가지 사용 장면을 중심으로 문구와 화면 예시를 구성했습니다.
