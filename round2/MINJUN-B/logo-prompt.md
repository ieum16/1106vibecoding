# 인사이트랩 로고 프롬프트

로고 제작 및 적용 완료: 남색·파랑의 눈 모양 아이콘으로 네 역할의 연결과 인사이트를 표현했습니다. 헤더·푸터·탭 아이콘에 적용하고 HTML에도 포함했습니다. 내장 이미지 생성 도구의 최종 프롬프트는 images/logo-generation.txt에, 원본은 images/insightlab-logo-original.png에 보관합니다.

## 기본 프롬프트
인사이트랩 팀의 로고를 만들어 줘.
남색 계열, 단순한 아이콘 + 팀 이름, 흰 배경, 정사각형.
데이터 분석부터 콘텐츠와 웹 제작까지 함께하는 팀을 표현해 줘.
팀 이름은 정확히 '인사이트랩'으로 넣어 줘.

## 아이콘 후보
- 연결된 점: 분야 간 연결을 표현
- 단순한 막대와 문서: 분석과 콘텐츠를 표현
- 네 개의 도형: 네 역할의 협업을 표현

## 수정 문장
- 더 단순하고 차분하게 만들어 줘.
- 아이콘만 따로 만들어 줘.
- 남색을 더 진하게 바꿔 줘.

아래 기본 프롬프트와 후보는 초기 기획 기록입니다. 실제 사용한 최종 프롬프트는 images/logo-generation.txt를 참조하세요.
