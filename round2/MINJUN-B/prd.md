# 인사이트랩 팀 홈페이지 PRD

- 문서 상태: 구현 기준 v1.0
- 작성일: 2026-11-06
- PRD는 무엇을, 누구를 위해, 어떻게 만들지 정리한 문서입니다.

## 1. 배경과 한 줄 소개
인사이트랩: 데이터 분석부터 콘텐츠와 웹 제작까지 함께하는 팀.
팀은 4명이며 역할은 기획, 데이터 분석, 콘텐츠, 제작입니다. 팀원은 닉네임을 사용하되 이번 화면에는 개별 소개를 넣지 않습니다.

## 2. 목적
팀을 알리고, 함께한 프로젝트를 보여 주고, 향후 협업 기회를 만듭니다. 이번 버전은 소개와 프로젝트 열람, 협업 문의 작성 팝업을 제공합니다. 실제 전송은 수신처와 연결 방식 준비가 필요합니다.

## 3. 누가 보는가
- 수업 동료·강사: 팀과 프로젝트를 이해하고 피드백합니다.
- 함께할 팀·파트너: 팀이 어떤 일을 하는지 프로젝트로 살펴봅니다.

## 4. 꼭 필요한 기능
1. 프로젝트 보기: 회사 홈페이지 리뉴얼 프로젝트 5개를 소개합니다.
2. 메뉴로 이동하기: 소개와 프로젝트 섹션으로 이동합니다.
3. 협업 문의 팝업: 사용자의 추가 요청에 따라 메인 버튼 아래와 페이지 하단의 함께하기 버튼에서 같은 팝업을 엽니다. 제목·내용·이름·이메일은 필수, 휴대폰은 선택입니다. 문의 내용 복사를 제공하고 실제 전송은 [준비 필요]로 표시합니다. 입력은 서버 전송·브라우저 저장 없이 열린 페이지 메모리에만 유지됩니다. 팝업은 닫기·Escape·바깥 영역 클릭으로 닫고, 키보드 초점을 복원합니다.

## 5. 페이지 구성
고정 헤더(임시 글자 로고, 소개·프로젝트 메뉴) → 팀 이름·한 줄 소개 → 대표 프로젝트와 추가 프로젝트 4개 → 푸터.
모든 내용은 한 페이지에 표시합니다.

## 6. 디자인 분위기
- 남색·흰색, 차분하고 믿음직하고 깔끔한 느낌.
- 구현 색: 남색 #14264B, 흰색 #FFFFFF, 보조 파랑 #315BCA, 연회색 #F3F5F9. 구체적인 색상 값은 구현 시 선택했습니다.
- 시스템 기본 글꼴, 넉넉한 여백, 일관된 글자 크기와 버튼.
- 참고 자료: https://getdesign.md/ — 색·글꼴·여백·구성 요소를 일관되게 정리하는 방식 참고. 특정 카탈로그 브랜드를 선택하거나 복제하지 않습니다.
- 로고: 남색·파랑의 눈 모양 아이콘. 네 역할의 연결과 인사이트를 표현하며 헤더·푸터·탭 아이콘에 적용합니다. 내장 이미지 생성 도구로 만들었으며 투명 PNG를 HTML 안에 포함합니다. 원본은 images/insightlab-logo-original.png에 보관합니다.

## 7. 콘텐츠
### 팀
- 이름: 인사이트랩
- 한 줄 소개: 데이터 분석부터 콘텐츠와 웹 제작까지 함께하는 팀
- 닉네임·개별 소개: 이번 화면에서 제외

### 프로젝트
사용자 요청에 따라 가상 프로젝트 5개와 AI 생성 홈페이지 콘셉트 이미지 5장을 표시합니다. 실제 고객사 작업·성과가 아닌 학습용 예시임을 명시합니다.

1. **모아리빙 — 회사 홈페이지 리뉴얼**
   - 가상의 생활용품 브랜드 모아리빙의 홈페이지 자료를 살펴보고, 방문자가 브랜드와 제품을 쉽게 이해하도록 리뉴얼 방향을 정리했습니다.
   - 기획 배경: 회사 소개와 제품 정보가 여러 메뉴에 흩어져 있고, 휴대폰에서는 글자가 작아 핵심 정보를 찾기 어려운 상황을 설정했습니다.
   - 메뉴 정리: 메뉴를 브랜드 소개 · 제품 · 소식으로 묶고, 첫 화면에서 주요 제품으로 바로 이동하도록 구성했습니다.
   - 콘텐츠 개선: 긴 회사 소개를 줄이고, 제품마다 용도·소재·관리 방법을 같은 순서로 정리했습니다.
   - 모바일 개선: 제품 카드를 한 줄에 하나씩 배치하고, 글자와 버튼을 키워 읽고 누르기 쉽게 설계했습니다.
   - 제안 결과물: 메뉴 구성안, 첫 화면 배치안, 제품 소개 문구를 담은 가상의 리뉴얼 제안서입니다.
   - 결과물 링크: [준비 필요]
2. **온리프 — 스킨케어 브랜드 홈페이지 리뉴얼**
   - 가상의 식물성 스킨케어 브랜드 온리프가 제품의 성분과 사용 방법을 명확하게 전달하도록 화면과 문구를 다시 구성했습니다.
   - 기획 배경: 감성 이미지에 비해 성분과 사용 순서 안내가 부족한 상황을 설정했습니다.
   - 개선 방향: 제품별 핵심 성분·사용 방법·자주 묻는 질문을 같은 형식으로 정리하고, 작은 화면에서도 읽기 쉬운 제품 카드를 제안했습니다.
   - 제안 결과물: 제품 소개 화면 구성안, 성분 안내 카드, 사용 순서 콘텐츠 예시입니다.
   - 결과물 링크: [준비 필요]
3. **그레인 커피 — 로스터리 홈페이지 리뉴얼**
   - 가상의 로스터리 그레인 커피를 처음 방문하는 사람도 원두의 맛과 매장 분위기를 쉽게 살펴볼 수 있도록 소개 페이지를 기획했습니다.
   - 기획 배경: 원두마다 설명 방식이 달라 취향에 맞는 커피를 고르기 어려운 상황을 설정했습니다.
   - 개선 방향: 원두 정보를 산미·고소함·추천 추출법으로 통일하고, 브랜드 이야기·원두 소개·매장 안내 순서로 내용을 정리했습니다.
   - 제안 결과물: 원두 소개 카드, 매장 안내 배치안, 브랜드 스토리 문구 예시입니다.
   - 결과물 링크: [준비 필요]
4. **오르빗 스튜디오 — 건축 스튜디오 홈페이지 리뉴얼**
   - 가상의 건축 스튜디오 오르빗의 공간 사진과 설계 의도가 함께 전달되도록 프로젝트 중심의 포트폴리오를 제안했습니다.
   - 기획 배경: 사진은 많지만 공간의 용도와 설계 의도를 파악하기 어려운 상황을 설정했습니다.
   - 개선 방향: 프로젝트를 주거·상업·공공 공간으로 나누고, 대표 사진과 함께 공간의 목적·설계 아이디어를 짧게 배치했습니다.
   - 제안 결과물: 프로젝트 목록 구성안, 사진 배치 규칙, 공간 소개 문구 예시입니다.
   - 결과물 링크: [준비 필요]
5. **플로우워크 — 업무 도구 소개 홈페이지 리뉴얼**
   - 가상의 협업 도구 플로우워크의 기능 나열을 줄이고, 팀이 어떤 문제를 해결할 수 있는지 이해하기 쉬운 소개 화면을 기획했습니다.
   - 기획 배경: 기능 이름과 전문 용어가 많아 도구의 쓰임을 이해하기 어려운 상황을 설정했습니다.
   - 개선 방향: 할 일 공유·진행 상황 확인·기록 모아보기의 세 가지 사용 장면을 중심으로 문구와 화면 예시를 구성했습니다.
   - 제안 결과물: 첫 화면 구성안, 사용 장면별 콘텐츠, 기능 설명 문구 예시입니다.
   - 결과물 링크: [준비 필요]

- 프로젝트 별도 상세 페이지
- 게시판, 실제 분석·지도 서비스, 관리자 기능

## 9. 기술과 배포
HTML·CSS·JS를 index.html 하나에 포함합니다. 외부 이미지·글꼴·라이브러리 없이 더블클릭으로 열 수 있습니다. 배포 대상은 GitHub와 Vercel입니다. 이번 요청에서는 파일 제작과 로컬 미리보기까지 진행합니다.

## 10. 완료 기준
- 팀 이름과 확정된 한 줄 소개가 표시됩니다.
- 가상 홈페이지 리뉴얼 프로젝트 5개와 생성 이미지 5장이 표시됩니다.
- 소개·프로젝트 메뉴가 해당 위치로 이동합니다.
- 휴대폰에서 메뉴가 열리고 선택·Escape로 닫힙니다.
- 375px, 768px, 1280px에서 가로 스크롤이 없습니다.
- 미정 콘텐츠는 [준비 필요]로 표시됩니다.
- 범위 밖 기능과 기존 브릿지팀 내용이 없습니다.
- 키보드 초점, 본문 바로가기, 화면 움직임 줄이기를 지원합니다.

## 11. 준비 필요
프로젝트별 실제 결과물 링크. 가상 이미지는 생성 완료 후 HTML에 포함합니다.
