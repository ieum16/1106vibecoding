# 2라운드 제출 · 우리 팀 홈페이지 올리기

4라운드 실습에서 만든 **팀 홈페이지**를 올려 주세요. 홈페이지 파일과 함께 **기획서(PRD), 홈페이지 캡처, 로고** 세 가지가 꼭 있어야 해요.
올린 캡처와 로고, PRD의 한 줄 소개는 강사 대시보드에 카드로 모여서 수업 중에 함께 봅니다.

> 가장 쉬운 방법: Codex에게 **"2과제 내고 싶어"** 라고 말하세요. 저장소의 [`AGENTS.md`](../AGENTS.md) 안내대로 빠진 파일을 같이 채우고, 확인을 받은 뒤 대신 올려 줍니다.

## 내 폴더에 들어갈 것

```
round2/
└── 내닉네임/              ← 1라운드와 같은 닉네임
    ├── index.html         ← 홈페이지 (꼭 · 닉네임 폴더 바로 안에)
    ├── style.css          ← 있으면 그대로
    ├── script.js          ← 있으면 그대로
    ├── images/            ← 사진·아이콘이 있으면 그대로
    ├── prd.md             ← 기획서 (꼭)
    ├── logo.png           ← 팀 로고 (꼭 · images/logo.png 에 있어도 돼요)
    ├── screenshot.png     ← 홈페이지 첫 화면 캡처 (꼭)
    ├── screenshot-2.png   ← 휴대폰 화면 등 (선택)
    └── README.md          ← 소개 글 (선택 · 양식 복사해서 채우기)
```

| 파일 | 어떻게 만들어요 |
|---|---|
| `prd.md` | 4-1에서 ChatGPT가 정리해 준 PRD를 메모장에 붙여 넣고 `prd.md`로 저장. 4-3에서 Codex가 만들었다면 `team-homepage/prd.md`에 이미 있어요 |
| `logo.png` | ChatGPT에 "우리 팀 로고 만들어 줘"로 만든 이미지를 받아서 `logo.png`로 저장. `.jpg`, `.svg`도 돼요 (`logo.jpg`) |
| `screenshot.png` | `index.html`을 크롬으로 열고 첫 화면을 캡처 (윈도우 `Win + Shift + S`, 맥 `Cmd + Shift + 4`). Vercel 주소가 있으면 그 화면을 찍어도 돼요 |
| `README.md` | 선택. [`_양식/README.md`](_양식/README.md)를 복사해서 한 줄 소개, 페이지 구성, **배포 주소**를 적으면 카드에 「사이트 열기」 버튼이 생겨요 |

## 웹에서 직접 올리기

1. 내 홈페이지 폴더(예: `team-homepage`)를 복사해서 이름을 **내 닉네임**으로 바꿔요.
2. 그 폴더에 `prd.md`, `logo.png`, `screenshot.png`가 있는지 확인해요.
3. 이 `round2` 폴더에서 **Add file → Upload files** → 닉네임 폴더를 **통째로** 끌어다 놓기 → **Commit changes**
4. 올린 뒤 내 닉네임 폴더를 열어 `index.html`이 바로 보이는지 확인해요.

## Codex로 올리기 (git)

Codex에게 이렇게 말하면 됩니다.

```
2과제 내고 싶어. 실습 저장소 https://github.com/ieum16/1106vibecoding 를 받아서(있으면 git pull)
AGENTS.md 의 「2과제 제출」 순서대로 진행해 줘. 내 닉네임은 ___, 홈페이지 폴더는 ___ 야.
```

## 올리기 전에 한 번 더

- 팀원 이름은 **닉네임**인가요? 실명, 사진 속 얼굴, 회사 이름, 부서, 연락처가 없나요?
- 문의 칸은 `team@example.com`, `#채널명` 같은 예시 값인가요?
- 캡처에 다른 탭, 메신저, 메일 제목이 찍히지 않았나요?

## 막힐 때

| 증상 | 해결 |
|---|---|
| 대시보드에 「index.html 이 한 단계 안쪽에 있음」 | 폴더 안에 폴더가 하나 더 생겼어요. 닉네임 폴더 바로 안에 `index.html`이 오게 다시 올리기 |
| 「prd.md 없음」 | 파일 이름을 `prd.md`로 (`PRD.md.txt` 아님). `기획서.md`도 알아봐요 |
| 「로고(logo.png) 없음」 | 파일 이름을 `logo.png`로. 다른 이름이면 대시보드가 못 찾아요 |
| 홈페이지에서 사진이 깨진다 | `images` 폴더도 같이 올렸는지, 파일 이름 대소문자가 맞는지 확인 |
| 카드에 「사이트 열기」가 없다 | `README.md`의 `## 배포 주소` 아래에 `https://○○○.vercel.app` 주소를 적기 |
