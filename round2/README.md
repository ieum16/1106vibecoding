# 2라운드 제출 · 우리 팀 홈페이지

4·5라운드에서 만든 **팀 홈페이지**를 제출해요. 아래 세 가지만 있으면 제출 완료입니다.

| 꼭 올릴 것 | 파일 | 어떻게 |
|---|---|---|
| 기획서 | `prd.md` | 4-1에서 ChatGPT가 정리해 준 PRD를 메모장에 붙여 넣고 `prd.md`로 저장. 4-3에서 Codex가 만들었다면 `team-homepage/prd.md`에 이미 있어요 |
| 로고 이미지 | `logo.png` | ChatGPT로 만든 팀 로고를 받아서 `logo.png`로 저장 (`.jpg` · `.svg` · `.webp`도 돼요) |
| 버셀 링크 | `README.md` | [`_양식/README.md`](_양식/README.md)를 내려받아 `## 배포 주소` 아래에 `https://○○○.vercel.app` 주소를 적기 |

있으면 더 좋아요: 홈페이지 첫 화면 캡처 `screenshot.png` (대시보드 카드 사진), 홈페이지 파일(`index.html`, `style.css`, `images/` …)

올린 로고 · PRD 한 줄 소개 · 버셀 링크는 강사 대시보드 카드에 모이고, 카드의 **「사이트 열기」**를 누르면 우리 팀 홈페이지가 열려요.

> 가장 쉬운 방법: Codex에게 **"2과제 내고 싶어"** 라고 말하세요. 저장소의 [`AGENTS.md`](../AGENTS.md) 안내대로 빠진 것을 같이 채우고, 확인을 받은 뒤 대신 올려 줍니다.

## 내 폴더 모습

```
round2/
└── 내닉네임/              ← 1라운드와 같은 닉네임
    ├── prd.md             ← 기획서 (꼭)
    ├── logo.png           ← 로고 (꼭)
    ├── README.md          ← 버셀 링크 적은 소개 글 (꼭)
    ├── screenshot.png     ← 홈페이지 캡처 (선택 · 추천)
    └── index.html …       ← 홈페이지 파일 (선택)
```

## 웹에서 직접 올리기

1. 바탕화면에 **내 닉네임** 이름의 새 폴더를 만들어요.
2. 그 안에 `prd.md`, `logo.png`를 넣어요.
3. [`_양식/README.md`](_양식/README.md)를 열고 오른쪽 위 다운로드 버튼으로 받아서 같은 폴더에 넣고, 팀 이름 · 한 줄 소개 · **배포 주소(버셀 링크)**를 채워요.
4. (선택) 홈페이지 첫 화면을 캡처해 `screenshot.png`로 넣어요. (윈도우 `Win + Shift + S`, 맥 `Cmd + Shift + 4`)
5. 이 `round2` 폴더에서 **Add file → Upload files** → 닉네임 폴더를 **통째로** 끌어다 놓기 → **Commit changes**

## 올리기 전에 한 번 더

- 팀원 이름은 **닉네임**인가요? 실명, 사진 속 얼굴, 회사 이름, 부서, 연락처가 없나요?
- 문의 칸은 `team@example.com`, `#채널명` 같은 예시 값인가요?
- 버셀 링크를 휴대폰에서 열어 봤나요?

## 막힐 때

| 증상 | 해결 |
|---|---|
| 대시보드에 「prd.md 없음」 | 파일 이름을 `prd.md`로 (`PRD.md.txt` 아님). `기획서.md`도 알아봐요 |
| 「로고(logo.png) 없음」 | 파일 이름을 `logo.png`로. 다른 이름이면 대시보드가 못 찾아요 (`images/logo.png`는 괜찮아요) |
| 「버셀 링크 없음」 | `README.md`의 `## 배포 주소` 아래에 `https://`로 시작하는 `○○○.vercel.app` 주소를 적기 |
| 버셀 주소가 없다 | 실습북 「5 폰에서 열기」로 먼저 배포하기. 막히면 강사에게 |
| 닉네임 폴더 안에 폴더가 하나 더 생겼다 | 한 단계 위 폴더를 끌었어요. 닉네임 폴더 바로 안에 `prd.md`가 오게 다시 올리기 |
