# NEXUS LAB 팀 홈페이지

## 한 줄 소개

조직의 복잡한 업무 흐름을 연결하고, 더 나은 디지털 도구를 만드는 가상 팀 NEXUS LAB의 소개 페이지입니다.

## 누구를 위해 만들었나요

협업 부서 구성원, 신규 입사자, 채용 지원자가 팀의 역할·구성·프로젝트를 빠르게 이해하도록 만들었습니다.

## 페이지 구성

- 터미널 상태 바와 팀 한 줄 소개
- 팀이 해결하려는 문제와 일하는 방향
- 팀 구성 카드
- 프로젝트 카드와 분야별 필터
- 프로젝트 외부 링크·문의 채널의 `[준비 필요]` 표시

## 배포 주소

https://boramaepark.vercel.app/

## 만들면서 배운 점

PRD의 정보를 화면 구조로 옮기고, 아직 정해지지 않은 내용은 지어내지 않고 표시하는 방법을 배웠습니다. 2라운드에서는 프로젝트 분야별 필터와 모바일 메뉴 동작을 보완했습니다.
