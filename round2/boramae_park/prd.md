## 1. 한 줄 소개

**NEXUS LAB은 조직의 복잡한 업무 흐름을 연결하고, 더 나은 디지털 도구를 만드는 가상 팀입니다.**

## 2. 목적

처음 보는 사람이 NEXUS LAB이 어떤 팀인지, 어떤 방식으로 일하는지, 지금까지 무엇을 만들었는지 빠르게 이해할 수 있는 팀 소개 홈페이지를 만듭니다.

## 3. 누가 보나요?

| 방문자 | 이 페이지에서 알고 싶은 것 |
|---|---|
| 협업 부서 구성원 | 우리 팀에 어떤 도움을 요청할 수 있는지 |
| 신규 입사자 | 팀의 역할과 팀원 구성 |
| 채용 지원자 | 팀의 분위기와 함께 만든 프로젝트 |

## 4. 꼭 필요한 기능

기능은 홈페이지가 할 수 있는 일입니다. 처음 버전은 아래 5개만 만듭니다.

1. 상단 메뉴를 누르면 해당 페이지 구역으로 부드럽게 이동
2. 팀 소개와 팀원 역할을 카드 형태로 표시
3. 함께 한 프로젝트를 카드 형태로 표시
4. 휴대폰에서는 메뉴를 열고 닫을 수 있는 버튼 제공
5. GitHub와 Vercel에서 별도 서버 없이 바로 열리는 정적 페이지

## 5. 페이지 구성

| 순서 | 구역 | 담을 내용 |
|---|---|---|
| 1 | 첫 화면 | 팀 이름, 한 줄 소개, 아래로 이동하는 버튼 |
| 2 | 팀 소개 | 팀이 해결하려는 문제와 일하는 방향 |
| 3 | 팀원 | 이름, 역할, 한 줄 소개 |
| 4 | 프로젝트 | 프로젝트 이름, 짧은 설명, 담당 분야 |
| 5 | 문의 | `[준비 필요]` — 실제 연락 방법이 정해진 후 추가 |
| 6 | 하단 | 팀 이름, 저작권 표시 |

## 6. 디자인 분위기

| 항목 | 결정 내용 |
|---|---|
| 전체 느낌 | 선명한 / 미래지향적 / 믿음직한 |
| 메인 색 | 짙은 남색 계열 |
| 포인트 색 | 라임 계열 |
| 글꼴 | 읽기 쉬운 고딕 계열 |
| 화면 구성 | 넉넉한 여백, 큰 제목, 카드 중심 |
| 휴대폰 | 한 줄 카드 배치, 좌우 여백 16px 이상, 가로 스크롤 없음 |

## 7. 콘텐츠

### 7-1. 팀원 소개

아래 인물과 내용은 모두 연습용 가상 정보입니다.

| 이름 | 역할 | 한 줄 소개 |
|---|---|---|
| NOVA-01 | 팀 리드 · 전략 | 팀의 문제를 선명한 방향으로 정리합니다. |
| PULSE-02 | 프로덕트 매니저 | 아이디어를 실제로 쓸 수 있는 경험으로 만듭니다. |
| GRID-03 | 프로덕트 디자이너 | 복잡한 흐름을 쉽게 이해되는 화면으로 바꿉니다. |
| LOOP-04 | 프론트엔드 엔지니어 | 빠르고 안정적인 웹 경험을 구현합니다. |
| SIGNAL-05 | 데이터 애널리스트 | 데이터에서 다음 행동의 힌트를 찾습니다. |

### 7-2. 함께 한 프로젝트

아래 프로젝트도 연습용 가상 사례입니다.

| 프로젝트 | 짧은 설명 | 담당 분야 |
|---|---|---|
| Flow Map | 팀 간 요청 흐름을 한눈에 정리하는 업무 지도 | 전략 · 데이터 |
| Signal Desk | 반복 문의를 모아 우선순위를 정하는 간단한 대시보드 | 프로덕트 · 디자인 |
| Launch Kit | 새 프로젝트의 시작 과정을 안내하는 내부 웹 도구 | 디자인 · 엔지니어링 |

### 7-3. 아직 준비되지 않은 콘텐츠

- 실제 로고: `[준비 필요]`
- 실제 문의 채널 또는 이메일: `[준비 필요]`
- 프로젝트 상세 페이지와 외부 링크: `[준비 필요]`

## 8. 만들지 않을 것

이번 버전에는 아래 기능을 만들지 않습니다.

- 로그인, 회원가입, 사용자 계정
- 데이터베이스, 서버, 관리자 페이지
- 문의 내용을 전송하거나 저장하는 폼
- 게시판, 댓글, 검색 기능
- 실제 회사 정보, 고객 정보, 성과 수치

## 9. 기술 조건

- `index.html` 파일 하나에 HTML, CSS, JavaScript를 모두 작성
- 별도 설치나 빌드 도구 없이 브라우저에서 열림
- GitHub 저장소에 올린 뒤 Vercel로 배포
- 데스크톱과 휴대폰에서 모두 읽기 좋게 반응형으로 구현

- [ ] 첫 화면에서 NEXUS LAB의 한 줄 소개가 바로 보인다.
