# 인사이트랩 팀 홈페이지 PRD

## 1. 한 줄 소개

인사이트랩은 일상 속 데이터를 분석해 새로운 발견을 만드는 팀입니다.

## 2. 목적

방문자가 인사이트랩이 어떤 팀인지 이해하도록 합니다. 팀의 소개, 구성원, 함께한 프로젝트를 한눈에 보여 줍니다.

## 3. 주요 방문자

데이터 분석에 관심 있는 사람을 대상으로 합니다. 처음 방문한 사람도 이해할 수 있도록 쉬운 표현을 사용합니다.

## 4. 꼭 필요한 기능

1. 팀 소개 보기: 팀의 한 줄 소개와 활동 방향을 보여 줍니다.
2. 팀원 소개 보기: 팀원 4명의 닉네임과 역할을 보여 줍니다.
3. 프로젝트 보기: 프로젝트 2개의 소개와 준비된 분석 결과를 보여 줍니다.
4. 메뉴로 이동하기: 메뉴를 누르면 같은 페이지의 해당 내용으로 이동합니다.

## 5. 페이지 구성

위에서 아래로 읽는 한 페이지 홈페이지로 만듭니다.

| 영역 | 들어갈 내용 |
|---|---|
| 상단 메뉴 | 팀 이름, 팀 소개·팀원·프로젝트 이동 메뉴 |
| 팀 소개 | 인사이트랩 이름, 한 줄 소개, 활동 방향 |
| 팀원 | 팀원 4명의 닉네임과 역할 |
| 프로젝트 | 따릉이 대여 패턴 분석, 우리 동네 카페 지도 |

휴대폰에서는 카드들을 세로로 배치하고, 메뉴와 글자가 화면 밖으로 잘리지 않게 합니다.

## 6. 디자인 분위기

친근하고 편안한 느낌으로 구성합니다.

- 밝은 크림색 배경
- 초록색 포인트
- 둥근 모서리의 카드
- 읽기 쉬운 글자 크기와 충분한 여백
- 배경과 구분이 잘 되는 글자색
