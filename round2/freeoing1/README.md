# 아이작 · ISAAC 팀 홈페이지

닉네임: **freeoing1** · 2라운드 과제

## 한 줄 소개

반복 업무를 자동화하고 고객의 장애 접수를 돕는 1인 팀 아이작의 소개 홈페이지입니다.

## 누구를 위해 만들었나요

기존 고객은 장애 전달에 필요한 정보를 준비하고, 새로운 고객은 자동화 서비스를 이해하고 문의할 내용을 정리할 수 있도록 만들었습니다.

## 페이지 구성

- 첫 화면: 아이작 소개, 자동화 문의 및 장애 접수 안내 버튼
- 아이작 소개: 반복 업무를 줄이는 1인 팀의 역할
- 자동화 서비스: 엑셀·자료 정리, 정기 보고서, 접수·처리 알림 자동화
- 우리가 만든 도구: 준비 중 안내
- 장애 접수: 증상·발생 시각·재현 순서·영향 범위 안내와 전달 양식
- 서비스 문의: 자동화 상담 준비 양식
- 하단: 팀 이름과 페이지 안내

## 화면

모노크롬 배경, 빨간 포인트, 굵고 얇은 제목 조합과 스크롤에 따른 렌즈 효과를 적용했습니다.
로고 파일은 `logo.png`이며, 홈페이지의 현재 상단은 글자 로고입니다.

## 만들면서 배운 점

기획서로 대상 고객과 방문 목적을 정리한 뒤, 서비스 소개와 장애 전달 안내를 구분해 구성했습니다.
스크롤 효과에는 움직임 멈춤 기능을 더했습니다. 문의 준비 양식은 복사할 수 있지만 실제 접수는 전송하지 않습니다.
ZTNature 글꼴 파일이 없어 설치된 글꼴을 우선 사용하고 Inter와 한글 대체 글꼴로 보완했습니다.
