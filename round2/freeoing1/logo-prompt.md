# 아이작 로고 만들기 — ChatGPT용 프롬프트

## 1. 기본 프롬프트

```text
아이작 팀의 로고를 만들어 줘.
검정 #000000와 빨강 #ef4444 계열, 단순한 아이콘 + 팀 이름,
흰 배경, 정사각형.
아이작은 반복 업무를 자동화하고 고객의 장애 접수를 돕는 1인 팀이야.
아이콘은 서로 이어진 각진 노드와 굵은 체크 표시를 단순한 도형으로 표현해 줘.
팀 이름은 한글 ‘아이작’으로 정확하게 넣어 줘.
절제된 검정 워드마크와 빨간 원형 포인트로 미니멀하게 표현해 줘.
한글 ‘아이작’을 주표기로 쓰고 영문 ISAAC은 작게 보조 표기해 줘.
작은 크기에서도 읽히게 하고, 흰 배경에서 빨간 심볼과 검정 글자가 분명하게 보여야 해.
입체 효과나 복잡한 배경 없이 평면적인 로고로 만들어 줘.
```

## 2. 아이콘 아이디어
| # | 아이디어 | 이유 |
|---|---|---|
| 1 | 연결된 노드 + 체크 | 자동화 흐름과 처리 완료를 함께 표현 |
| 2 | 둥근 순환 화살표 + 작은 번개 | 반복 업무와 빠른 처리를 표현 |
| 3 | 한글 ‘아’의 단순한 기하학적 심볼 | 팀 이름을 기억하기 쉽게 표현 |

## 3. 다시 뽑을 때 쓰는 문장
- 더 단순하게, 선 굵기를 일정하게 해 줘.
- 아이콘만 따로, 글자 없이 한 장 더 만들어 줘.
- 포인트 빨강을 정확히 #ef4444로 맞추고 여백을 더 넓게 해 줘.
- 팀 이름이 정확히 ‘아이작’으로 읽히게 수정해 줘.

## 4. 다 만들었으면
1. 이 프롬프트로 만든 로고 중 마음에 드는 이미지를 이 대화에 올린다.
2. 홈페이지에서 images/logo.png로 사용한다.
3. 참고할 사이트 화면이 있으면 함께 올린다. images/reference.png로 참고한다.
4. 로고 없이 먼저 시작하려면 임시 글자 로고로 제작하고 나중에 교체한다.
