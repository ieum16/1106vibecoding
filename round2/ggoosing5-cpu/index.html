05 / Good questions

궁금한 점이
있으신가요?

제안하기 전에 알아두면 좋은 내용입니다.

아이디어는 어떻게 제안하나요?

제목, 해결하려는 문제, 아이디어 설명, 기대 효과를 정리해 주세요. 예상 비용과 구현 방법은 알고 있는 경우에만 작성하면 됩니다. 위 양식은 작성 체험이며 실제 제출 경로는 [준비 필요]입니다.

어떤 기준으로 가능성을 검토하나요?

최초아이디어팀은 아이디어 기획, 구현 가능성 검토와 시장조사를 담당합니다. 공식 검토 기준과 승인 절차는 [준비 필요]입니다.

체험에서 입력하면 팀에 전달되나요?

아니요. 제안 내용과 점수·의견은 전송되거나 저장되지 않습니다. 새로고침하면 입력과 체험 결과가 사라집니다. 승인과 부서 지정도 체험이며 실제 업무 처리가 아닙니다.

프로젝트의 실제 진행 상황을 알 수 있나요?

확인된 정보만 소개합니다. 현재 실제 진행 단계와 검증 결과는 [준비 필요]입니다. 체험 화면의 단계와 점수는 실제 진행 현황이나 구성원의 평가 결과가 아닙니다.
