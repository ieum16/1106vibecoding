# 연습1 · 하루 건강 확인

## 한 줄 소개

대상자별 하루 건강 확인 기록을 모아 월별 현황을 살펴보고 엑셀로 내려받는 웹 도구입니다.

## 누구를 위해 만들었나요

대상자별 건강 확인 기록을 관리하는 사용자를 위한 도구입니다. 가상 대상자를 등록하고 매일 확인 내용을 기록할 수 있습니다.

## 페이지 구성

- 월별 현황: 사람별 이번 달 기록과 상태 확인
- 오늘 확인: 날짜별 건강 확인 기록 입력
- 대상자 관리: 대상자 번호와 질환, 주의사항 관리
- 제출 · 백업: 월별 엑셀 다운로드와 JSON 백업·복원
