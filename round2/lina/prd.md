# 연습1 · 하루 건강 확인

## 한 줄 소개

대상자별 하루 건강 확인 기록을 모아 월별 현황을 살펴보고 엑셀로 내려받는 웹 도구입니다.

## 목적과 사용 대상

- 목적: 매일의 확인 기록을 대상자별로 모으고 월별 자료를 정리합니다.
- 사용 대상 (가정): 여러 대상자의 건강 확인 기록을 관리하는 사용자입니다.
- 연습에서는 실제 이름 대신 가상 대상자 번호를 사용합니다.

## 페이지 구성과 주요 기능

1. 월별 현황: 조회 월을 선택하고 대상자별 확인 일수와 상태를 살펴봅니다.
2. 오늘 확인: 날짜별 확인 항목, 기온, 혈압·혈당, 조치 내용과 조치 상태를 기록합니다. 같은 대상자·날짜로 다시 저장하면 기존 기록을 수정합니다.
3. 대상자 관리: 대상자 번호, 질환, 기타 메모와 의료진 주의사항을 등록·수정합니다.
4. 제출 · 백업: 월별 요약과 상세 기록을 엑셀로 내려받고 JSON으로 백업·복원합니다.

## 구현과 디자인

- HTML, CSS, JavaScript가 포함된 단일 index.html로 동작합니다.
- 자료는 브라우저 내부 저장소에 저장합니다.
- 메인 색은 초록색 #234c42이며 밝은 배경과 둥근 카드를 사용합니다.
- 화면의 초록색 ‘연’ 표시를 별도 제출 로고 logo.svg로 옮겼습니다.
- 모바일 화면을 위한 반응형 스타일이 포함되어 있습니다.

## 기록 해석

- 기록이 없는 날을 정상으로 계산하지 않습니다.
- 상태 표시는 진단이나 안전 확정이 아니며, 질문과 분류는 의료진 검토 전 초안입니다.
- 저장된 자료는 정기적으로 백업합니다.
