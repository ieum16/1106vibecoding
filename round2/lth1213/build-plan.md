# bell 팀 홈페이지 제작 계획서

## 1. 만들 것
- 외부 파트너가 팀의 역할을 이해하고 협업을 제안할 수 있는 한 장짜리 소개 페이지.
- 기준 문서: prd.md. wise-design.md의 Meadow-glass ledger 기준 라임·숲색·흰색 디자인.
- 홈페이지 구현을 완료했으며, 사용자 제공 디자인 문서를 적용해 수정했다.

## 2. 파일 구조
```text
team-page/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html          ← 구현 완료
└─ images/             ← 이미지 준비 시 생성
   ├─ logo.png         ← 골든벨 로고, 선택
   └─ reference.png    ← 참고 이미지, 선택
```

## 3. 준비물 체크
| 준비물 | 상태 | 없을 때 |
|---|---|---|
| images/logo.png | 없음 · 골든벨 방향과 프롬프트 준비 완료 | B 글자 인라인 SVG 임시 로고 사용 후 이미지로 교체 |
| images/reference.png | 없음 | PRD의 디자인 가이드를 따름 |
| 문의 이메일 | 예시 team@example.com | 예시 주소임을 화면에 표시 |
| 업무 및 메뉴 | 사용자 동의 완료 | PRD에 기재한 4개 업무와 5개 메뉴 사용 |
| 제작 방향 확인 | 승인 완료 | 사용자 요청에 따라 디자인 문서 적용 |

## 4. 만드는 순서
| 단계 | 할 일 | 확인할 것 |
|---|---|---|
| 1 | 헤더·섹션 5개·푸터 구성 | 메뉴와 섹션 ID 일치 |
| 2 | 색·글꼴·간격 변수 적용 | 라임 #9FE870, 숲색 #163300, 본문 #0E0F0C |
| 3 | 한 줄 소개와 협업 버튼 | 버튼으로 문의 영역 이동 |
| 4 | 업무 카드 4개 | 설명과 요청 예시가 PRD와 일치 |
| 5 | 협업 분야와 제안 흐름 | 확인되지 않은 성과·약속이 없는지 |
| 6 | 도구 준비 중 카드 | 점선 테두리와 준비 중 배지 |
| 7 | 문의 안내 | 필요한 정보 3개, 예시 이메일 표시 |
| 8 | 로고와 모바일 메뉴 | 이미지가 없어도 정상 표시, 메뉴 키보드 조작 |
| 9 | 화면·기능 확인 | 375px와 1280px, 가로 스크롤과 메뉴 이동 확인 |

## 5. 섹션별 구현 메모
| 섹션 | 레이아웃 | 데스크톱 → 휴대폰 |
|---|---|---|
| 헤더 | 왼쪽 로고·bell, 오른쪽 고정 메뉴 | 768px 미만 햄버거 메뉴 |
| 팀 소개 | 왼쪽 소개, 오른쪽 로고 또는 간결한 시각 요소 | 세로 배치 |
| 하는 일 | 카드 4개 | 2열 → 2열 → 1열 |
| 협업 분야 | 과제 카드 3개와 간단한 흐름 | 3열 → 1열 |
| 도구 | 점선 준비 중 카드 | 넓이에 맞춰 1열 |
| 문의 | 남색 배경, 제안 안내와 예시 주소 | 세로 배치 |

CSS·JS는 index.html 안에 작성한다. 모바일 좌우 여백은 16px. 작은 글자는 #23221F 또는 딥 틸을 사용한다. 로고 경로 로딩 실패 시 임시 SVG를 보이고, 파일이 추가되면 다음 열기에서 실제 로고를 표시한다.

## 6. 확인 방법
- 브라우저 미리보기가 가능하면 1280px와 375px에서 확인한다.
- 문서 너비가 화면 너비를 초과하지 않는지 확인한다.
- 메뉴 5개와 협업 제안 버튼, 모바일 메뉴 열기·닫기를 확인한다.
- 키보드 Tab·Enter 조작과 포커스, 글자 대비를 확인한다.
- 로고 파일이 없는 경우의 대체 표시를 확인한다.
- prd.md 12번 완료 기준을 점검한다.
- 브라우저 미리보기를 사용할 수 없으면 그 한계를 안내하고 index.html 더블클릭으로 확인하도록 안내한다.
