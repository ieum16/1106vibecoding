# Bell 세로형 로고

## 현재 로고
- 파일: images/logo.png
- 내장 image_gen 도구로 생성한 투명 배경 PNG.
- 홈페이지 헤더와 첫 화면 소개 카드에 적용했다.
- 표기: Bell (대문자 B, 소문자 ell).

## 사용한 생성 프롬프트
신사업을 발굴하고 반복 업무를 자동화 도구로 바꾸는 Bell 팀의 세로형 로고를 만들어 줘. 정사각형 캔버스, 실제 투명 배경. 위에는 둥근 골든벨 아이콘, 아래에는 정확히 Bell을 배치하고 중앙 정렬해 줘. 금색 종의 기준 색은 #C99B3B이며, 입체적인 금속 질감·그라데이션·빛 반사·그림자·장식 디테일을 포함해 줘. 작은 울림 선 두 개로 역동성과 새로운 가능성의 시작을 표현해 줘. 글자는 짙은 숲색 #163300의 굵고 단정한 산세리프. 라임 #9FE870 홈페이지와 어울리게. 주변 여백은 넉넉하게 두고 작은 크기에서도 알아볼 수 있게. 로고 한 개만 표시하며 목업·테두리·추가 문구·워터마크는 제외해 줘.

## 향후 교체
images/logo.png를 새 로고 파일로 교체하면 홈페이지의 두 이미지가 같은 로고를 표시한다. 브라우저에서 이전 이미지가 보이면 새로고침한다.
