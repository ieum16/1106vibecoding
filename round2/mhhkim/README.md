# 일이음 팀 홈페이지

## 한 줄 소개

반복 업무를 자동화해 더 중요한 일에 집중하도록 돕는 일이음 팀의 소개 홈페이지입니다.

## 누구를 위해 만들었나요

협업 부서와 신규 입사자가 팀의 역할을 한눈에 이해하고, 어떤 업무를 함께 개선할 수 있는지 판단하도록 만들었습니다.

## 페이지 구성

- 팀 소개: 영문 제목과 한글 소개, 4개 업무 요약 타일
- 하는 일: 엑셀 취합·업데이트, 정기 업무보고, 매입·매출계획, 입출고 관리
- 도구 예시: 분야별 필터와 가상 데이터 예시 창
- 협업 안내: 협업하기 좋은 업무와 진행 단계
- 자주 묻는 질문: 질문별 답변 펼치기
- 문의: 예시 채널과 문의 양식 복사

## 만들면서 배운 점

기획서를 바탕으로 페이지를 만들고, 글자 크기와 설명 분량을 조정하며 가독성을 개선했습니다. 영문 제목과 한글 본문을 조합하고, 블랙·형광 보라색과 CSS 도형으로 디자인을 다듬었습니다. GitHub 업로드와 Vercel 배포를 진행했으며 휴대폰에서도 홈페이지가 열리는 것을 확인했습니다.
