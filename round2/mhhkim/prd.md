# 일이음 팀 소개 페이지 PRD

## 한 줄 소개

반복 업무를 자동화해 더 중요한 일에 집중하도록 돕는 일이음 팀의 소개 홈페이지. 협업 부서와 신규 입사자가 역할과 협업 가능한 업무를 한눈에 파악하도록 한다.

최신 디자인 변경: 사용자 요청에 따라 검정 바탕과 형광 보라색 #BF71FF로 전환했다. 배경에는 CSS로 만든 은은한 빛 구체, 타원 궤도, 떠 있는 기하학 도형과 점 패턴을 추가했다. 장식은 콘텐츠 뒤에 위치하고 클릭을 가로채지 않으며, 동작 줄이기 설정에서는 애니메이션을 끈다. 영문 제목·기존 로고·확대된 본문·업무 타일은 유지한다. 이 변경은 아래의 이전 청록색 가이드보다 우선한다.

PRD는 무엇을, 누구를 위해, 왜 만드는지 정리한 제품 요구사항 문서다. 협업 부서와 신규 입사자가 일이음의 역할을 한눈에 이해하고 협업 가능성을 판단하도록 한다.

## 1. 배경과 문제

팀의 업무와 협업 가능한 범위를 함께 보여줘야 방문자가 자신의 반복 업무를 연결해 볼 수 있다. 긴 팀 소개 대신 업무별 카드와 구체적인 요청 예시를 제공한다.

## 2. 목표와 성공 기준

| 목표 | 검토 기준 |
|---|---|
| 팀 역할을 빠르게 이해 | 처음 보는 사람이 1분 안에 주요 업무 4가지 중 3가지를 설명할 수 있음 (가정: 검토 목표) |
| 협업 가능성 판단 | 각 업무 카드에서 자기 업무와 유사한 요청 예시를 찾을 수 있음 |
| 오해 없는 도구 소개 | 도구 4개 모두 예시·준비 중 상태를 표시하고 실제 작동하는 서비스처럼 표현하지 않음 |

## 3. 대상 사용자

| 대상 | 궁금한 것 | 페이지가 줄 답 | 기대 행동 |
|---|---|---|---|
| 협업 부서 | 우리 업무도 같이 개선할 수 있나? | 지원 업무와 협업 사례 | 관련 업무와 준비 자료를 판단 |
| 신규 입사자 | 무슨 일을 하는 팀인가? | 한 줄 소개와 업무 4개 | 팀 역할과 문의 경로 이해 |

## 4. 범위

이번 범위는 한 장짜리 반응형 소개 대시보드, 도구 예시, 협업 안내, FAQ, 예시 문의 정보다. 엑셀 처리·보고서 생성·계획 수립·실시간 재고 연동 기능 자체의 구현과 로그인, 서버, 실제 문의 접수는 포함하지 않는다. 화면의 도구 카드는 서비스 기획 예시다.

## 6. 화면 구성

데스크톱은 업무 카드 4열과 넓은 안내 패널을 조합해 대시보드처럼 배치한다. 성과 수치나 운영 현황은 임의로 만들지 않는다. 요약에는 확정된 정보인 업무 영역 4개와 대상 사용자만 표시한다.

## 7. 콘텐츠 상세

### 7.1 팀 소개

- 팀 이름: 일이음
- 제목: 반복은 줄이고, 일을 잇다.
- 설명: 반복 업무를 자동화해 더 중요한 일에 집중하도록 돕는 팀.
- 버튼: 협업 가능한 업무 보기 / 문의 준비하기.
- 소속과 팀원 수: 미표시 (가정: 소개에 불필요).

### 7.2 주요 업무와 도구 예시

| 업무 | 설명 | 요청 예시 | 도구 예시 |
|---|---|---|---|
| 엑셀 취합·업데이트 | 기본 양식에 맞춰 팀별 내용을 취합하고 기준 파일 업데이트 | 같은 양식으로 받은 팀별 파일을 하나로 모으고 싶어요 | 엑셀 취합 도우미 |
| 정기 업무보고 작성 | 주기적으로 반복되는 업무보고의 자료 정리와 작성 지원 | 매주 같은 형식으로 만드는 보고서 초안을 줄이고 싶어요 | 업무보고 초안 생성기 |
| 정기 매입·매출계획 작성 | 실적과 예정 자료를 모아 정기 계획표 작성 지원 | 팀별 실적과 예정 거래를 모아 월간 계획을 만들고 싶어요 | 매입·매출계획 도우미 |
| 실시간 입출고 관리 | 입출고 내역과 재고 변동을 연결해 현황 파악 지원 | 입출고 변화와 재고를 한눈에 보고 싶어요 | 입출고 현황 보드 |

도구 카드마다 '도구 예시'와 '준비 중'을 명시한다. 실시간 반영 주기와 연동 가능성은 데이터 소스와 운영 환경을 확인한 후 협의한다.

### 7.3 협업 안내

협업하기 좋은 일: 같은 양식으로 반복 수집하는 자료, 정기적으로 복사·정리하는 보고, 여러 파일을 대조하는 계획, 업데이트가 잦은 입출고 현황.

준비 자료: 현재 업무 흐름, 실행 주기, 사용하는 양식의 가상 예시, 원하는 결과물. 진행 흐름은 '업무 공유 → 범위 확인 → 작은 시범 적용 → 검토·개선'으로 제안한다 (가정: 협업 절차).

### 7.4 FAQ

- 어떤 일을 요청하나요? 반복되는 취합·정리·보고·현황 관리 업무부터 함께 살펴봅니다.
- 무엇을 준비하나요? 업무 흐름, 주기, 예시 양식, 원하는 결과를 준비합니다.
- 도구를 바로 사용할 수 있나요? 현재 도구 카드는 협업 아이디어를 설명하는 예시이며 준비 중입니다.
- 입출고를 바로 실시간 연동하나요? 데이터 소스와 연결 방식을 먼저 확인하고 반영 주기를 협의합니다.

### 7.5 문의

| 항목 | 값 |
|---|---|
| 요청 채널 | #일이음-문의 (예시) |
| 이메일 | team@example.com (예시) |
| 응답 시간 | 협의 후 안내 (가정) |

예시 연락처임을 명시한다. 실제 전송 대신 요청 양식 복사 버튼을 제공한다 (가정). 복사 실패 시 선택 가능한 텍스트를 표시한다.

## 8. 디자인 가이드

| 항목 | 값 |
|---|---|
| 바탕 | 검정에 가까운 #080B12 |
| 카드 표면 | #101725 |
| 주조색 | 남색 #172B4D |
| 강조 | 밝은 남색 계열 #6D91D5 (가정: 가독성 보완) |
| 본문 | #F1F5FF, 보조 글자 #ADB8CC |
| 느낌 | 깔끔한 / 한눈에 들어오는 / 대시보드형 |
| 글꼴 | Pretendard, 시스템 한글 글꼴 대체 |
| 카드 | 16px 모서리, 얇은 테두리, 절제된 그림자 (가정) |
| 로고 | images/logo-en.png, 영문 Ilieum 필기체, 밝은 획과 남색 끝선 |
| 참고 디자인 | 사용자 제공 Synapse 디자인 프롬프트: 유리 질감 메뉴, 큰 세리프 제목, 은은한 빛, 모듈 카드 |

글꼴은 사용자가 선택한 '반복은 줄이고, 일을 잇다.'의 Noto Sans KR로 통일하고 시스템 한글 글꼴을 대체로 사용한다. 본문 16–18px, 카드 제목 20–22px, 보조 표기 13–15px를 기준으로 한다. 검정·남색에 청록 #58E2CC를 추가해 핵심 문구, 주요 버튼, 선택된 필터와 아이콘을 강조한다. 청록 버튼의 짙은 글자 대비는 10.58:1, 카드 위 보조 본문은 9.67:1이다.

첫 화면은 영문 대형 제목 'Workflow, in harmony.'와 한글 문구 '반복은 줄이고, 일을 잇다.', 4개 업무 요약 타일로 구성한다. 사용자 피드백으로 왼쪽 제목 영역의 영문 Instrument Serif와 그라데이션 이탤릭 조합을 복원했다. 본문과 나머지 제목은 Noto Sans KR을 유지한다. 기존 가상 그래프·중복 업무 목록·가로 요약 띠를 제거한다. 주요 업무와 도구는 데스크톱 2열, 휴대폰 1열로 배치하고 설명을 짧게 줄인다. 도구의 장식 이미지 대신 아이콘을 사용하며 상세 가상 데이터는 버튼으로 연다. FAQ 답변은 접힌 상태에서 필요한 것만 확인한다. 움직임을 줄여 정보에 집중하도록 한다.

## 9. 반응형과 접근성

- 375px부터 데스크톱까지 가로 스크롤 없이 구성한다.
- 업무·도구 카드는 데스크톱·태블릿 2열 → 휴대폰 1열. 첫 화면 업무 요약은 2×2 타일.
- 640px 미만은 햄버거 메뉴, 좌우 여백 16px.
- 메뉴·FAQ·복사 버튼은 키보드 조작과 명확한 포커스를 지원한다.
- 짙은 남색 위의 작은 글자는 밝은 색으로 두고 본문 대비 4.5:1을 목표로 한다.
- 로고 대체 텍스트는 '일이음'으로 지정한다.

## 10. 기술 조건

index.html 하나에 CSS·JS를 포함하며 빌드나 서버 없이 열린다. 로고는 images/logo-en.png를 참조한다. 외부 의존은 선택적인 글꼴 CDN으로 제한한다. 고정 메뉴와 섹션 이동, FAQ 펼치기, 요청 양식 복사, 도구 분야 필터와 가상 데이터 예시 창을 구현한다.

## 13. 열린 질문

- 실제 문의 채널은 추후 지정하며 현재는 예시를 사용한다.
- 팀 소속·인원은 생략한다. 필요하면 추가한다.
- 제안한 협업 절차와 FAQ, 요청 양식 복사 기능은 계획 검토 때 변경할 수 있다.
- 사용자의 추가 디자인 요청과 제작 지시에 따라 index.html을 생성했다.
- 코드 문법·메뉴 대상·ID 중복·이미지 경로 확인 완료. 앱 보안 정책으로 로컬 파일의 브라우저 미리보기가 차단되어 실제 화면과 인터랙션 검증은 미완료다.
