# 떡잎방범대 홈페이지

## 한 줄 소개
동네 주민에게 오늘의 안전 활동과 봉사 소식을 전하고, 불편 신고 안내를 확인할 수 있는 팀 홈페이지입니다.

## 누구를 위해 만들었나요
동네 주민을 위해 만들었습니다. 오늘의 활동과 봉사를 확인하고, 생활 속 불편 사항을 알리는 방법을 찾을 수 있습니다.

## 페이지 구성
- 첫 화면: 떡잎방범대 소개
- 오늘의 활동
- 오늘의 봉사
- 불편 신고 안내
- 대원 소개
- 마무리 안내: 우리 동네, 같이 지켜요!
