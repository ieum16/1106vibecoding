# 추적자 — Location Tracker 로고 프롬프트

## 1. 기본 프롬프트
아래 내용을 ChatGPT 이미지 생성에 붙여 넣습니다.

```text
‘추적자’라는 1인 팀의 주소 검색 도구 ‘Location Tracker’ 로고를 만들어 줘.
조금 밝고 신뢰감 있는 남색(#315D9B) 계열, 단순한 위치 핀 아이콘 + 영문 이름,
흰 배경, 정사각형.
주소를 입력하면 지도에서 위치와 좌표를 확인하는 서비스야.
아이콘은 지도 핀 안에 작은 중심점을 둔 간결한 형태로 표현해 줘.
영문 글자는 정확히 ‘Location Tracker’로 넣어 줘.
깔끔하고 실용적이며 누구에게나 쉽게 느껴지는 인상으로,
작은 모바일 헤더에서도 알아보기 쉽게 만들어 줘.
입체 효과와 복잡한 장식 없이 넉넉한 여백을 두고 구성해 줘.
```

## 2. 아이콘 아이디어
| # | 아이디어 | 이유 |
|---|---|---|
| 1 | 중심점이 있는 지도 핀 | 위치 찾기 기능을 바로 전달 |
| 2 | 접힌 지도 위 작은 핀 | 주소 검색과 지도 연결을 표현 |
| 3 | 돋보기 안의 핀 | 검색 후 장소를 확인하는 흐름을 표현 |

## 3. 다시 만들 때 쓸 문장
- ‘핀 모양을 더 단순하게 하고 그림자를 없애 줘.’
- ‘색을 #315D9B에 가깝게, 너무 어둡지 않은 남색으로 바꿔 줘.’
- ‘글자 철자를 정확히 Location Tracker로 수정해 줘.’
- ‘아이콘만 따로, 글자 없이 정사각형으로 한 장 더 만들어 줘.’
- ‘가로형 헤더에 쓸 수 있도록 아이콘 왼쪽, 영문 이름 오른쪽으로 배치해 줘.’

## 4. 적용 방법
마음에 드는 이미지를 이 대화창에 올리거나 `team-page/images/logo.png`에 넣습니다. 참고 화면이 있다면 `team-page/images/reference.png`에 넣습니다.

이미지 없이 시작하면 간단한 핀 SVG와 실제 텍스트 ‘Location Tracker’를 조합합니다. 나중에 로고 파일을 추가하면 교체할 수 있게 제작합니다. 영문 서비스 이름은 유지하고 작은 팀 이름으로 ‘추적자’를 사용할 수 있습니다.
