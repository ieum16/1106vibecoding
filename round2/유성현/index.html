처음 사용하는 작업용 필터

  1. 요건 원문과 찾을 영역을 입력합니다.
  2. ‘피그마 연결’로 내 파일을 불러오거나, 가상 예시·JSON 파일로 시험합니다.
  3. ‘수정 영역 찾기’를 누르고 후보별 근거와 검토 상태를 확인합니다.
  4. 조건표를 원문과 맞춘 뒤 ‘초안 다시 만들기’를 누릅니다.
  5. 초안을 편집·복사하고, 작업 기록을 백업합니다.

피그마 연결은 두 가지입니다. ① 개인 액세스 토큰으로 이 화면에서 바로 읽기 ② 동봉한 피그마 플러그인(figma-plugin 폴더)으로 내보낸 JSON 붙여넣기. 화면 프레임 안의 텍스트를 가까운 묶음(영역)으로 모아 검색합니다. AI 문장 분석과 피그마 수정은 하지 않습니다.

JSON 파일은 아래 입력 양식, 피그마 API 응답 원본, 플러그인 내보내기 파일을 모두 읽습니다.

{
  "source": "가상 신청 화면",
  "screens": [{
    "screen": "신청정보 · 모바일",
    "area": "요금안내서 수신 방법",
    "nodeId": "demo:101",
    "text": "요금안내서 수신 방법\n이메일 / 우편",
    "path": "가입 > 신청정보"
  }]
}

화면 영역마다 고유한 nodeId를 사용하세요. 선택 필드 link에는 HTTPS 피그마 링크를 넣을 수 있습니다.

첫 실행의 5개 화면 영역은 모두 가상 예시입니다. 기본 규칙은 기기변경 비노출, 번호이동·신규가입 노출이며 원문 변경 시 조건표도 직접 확인해야 합니다.

피그마 연결

방법 1 · 토큰으로 바로 읽기

피그마 → 프로필 → Settings → Security → Personal access tokens에서 File content: Read only 권한으로 토큰을 만들어 붙여넣으세요.

토큰은 피그마 API(api.figma.com)에만 보내며 백업 파일에 포함하지 않습니다.

방법 2 · 플러그인 결과 붙여넣기

토큰 사용이 막혀 있거나 요청 한도에 걸리면 피그마 데스크톱 앱에서 Plugins → Development → Import plugin from manifest…로 figma-plugin/manifest.json을 등록하고 실행해 복사한 JSON을 붙여넣으세요.
