# AI 표준팀 팀 홈페이지 제작 계획서

## 1. 만들 것
초보 직원용 팀 소개·개발 가이드·스킬 탐색·제작 요청을 담은 단일 페이지. 기준 문서: prd.md.

## 2. 파일 구조
- prd.md: 요구사항
- logo-prompt.md: 로고 제작 프롬프트
- build-plan.md: 이 계획서
- index.html: 제작 승인 후 생성
- images/logo.png: 최종 로고, 선택
- images/reference.png: 참고 화면, 선택

## 3. 준비물 체크
| 준비물 | 상태 | 없을 때 |
|---|---|---|
| 최종 로고 | 없음 | 팀 이름 첫 글자로 임시 SVG 로고, 이미지 추가 시 교체 |
| 참고 이미지 | 없음 | PRD의 색과 구성 적용 |
| 문의 채널 | 예시 | #채널명, team@example.com만 사용 |
| 실제 스킬 파일 | 없음 | 준비 중 카드와 사용 예시 |

## 4. 만드는 순서
1. 의미 있는 HTML 구조와 고정 메뉴·5개 주요 섹션 구현.
2. 네이비·청록·보라 색상 변수와 Pretendard, 밝은 본문 카드 적용.
3. 메인 문구·시작 버튼·팀 업무 카드 구성.
4. 단계별 가이드와 스킬 검색·분류·준비 중 표시 구현.
5. 요청문 생성·복사·수동 복사 대체 동작 구현. 실제 전송 없음 안내.
6. FAQ 접기·펼치기와 모바일 메뉴 구현.
7. 반응형·접근성·기능 확인 후 수정.

## 5. 섹션별 구현 메모
| 섹션 | 구성 | 모바일 |
|---|---|---|
| 헤더 | 심벌·팀 이름·메뉴 | 햄버거 메뉴 |
| 첫 화면 | 제목·행동 버튼·기하학 그래픽 | 한 열, 문구 우선 |
| 팀 소개 | 역할 3개 카드 | 한 열 |
| 시작 가이드 | 시작 순서·4개 안내 카드 | 한 열 |
| 스킬 모음 | 검색·카테고리·3개 예시 | 한 열 |
| 제작 요청 | 양식·절차·요청문 미리보기 | 위아래 배치 |
| FAQ | 5개 질문 | 접기·펼치기 |

## 6. 확인 방법
- 1280px와 375px에서 문구·카드·메뉴·가로 넘침 확인.
- 키보드만으로 메뉴, 검색, FAQ, 요청 양식 사용 확인.
- 검색 결과 없음, 빈 필수 항목, 복사 실패와 수동 복사 확인.
- 준비 중 카드가 실제 설치 기능처럼 오해되지 않는지 확인.
- 브라우저 미리보기 불가 시 사용자가 index.html을 열어 확인하도록 안내.
- GitHub 업로드는 팀 페이지 제출 경로 확정 후 진행.

## 7. 만든 뒤 고치기 예시
- 스킬 카드를 하나 더 넣어 줘.
- 화면을 더 밝게 만들어 줘.
- 시작 가이드를 더 쉬운 표현으로 바꿔 줘.

현재 단계는 계획서 작성 완료이며, 홈페이지와 최종 로고는 아직 생성하지 않았습니다.
