매끄러운 답변도 확인이 필요해요.

② 인용한 출처가 실제로 해당 내용을 뒷받침하는지 확인하세요.
③ 빠진 조건과 과장된 표현을 수정하세요.

05 / HELP DESK

궁금한 점을
먼저 확인해 보세요.

문의 채널 예시: #채널명
이메일 예시: team@example.com
실제 문의처는 운영 시 별도로 안내합니다.
스킬이란 무엇인가요?

특정 작업을 반복해서 수행할 수 있도록 절차와 기준을 정리한 안내입니다. 도구에 맞는 스킬을 사용하면 원하는 형식과 과정을 일관되게 적용하는 데 도움이 됩니다.

스킬은 어떻게 설치하나요?

사용하는 AI 도구가 스킬을 지원하는지 먼저 확인하세요. 배포된 스킬의 공식 설치 안내에 따라 추가합니다. 이 페이지의 스킬은 아직 준비 중이므로 설치 파일을 제공하지 않습니다.

원하는 답변이 나오지 않으면 어떻게 하나요?

작업의 목적과 대상, 결과 형식을 더 구체적으로 알려주세요. 예시를 하나 제공하거나 큰 작업을 작은 단계로 나누는 것도 좋습니다. 결과의 사실 여부는 별도로 확인하세요.

어떤 정보를 입력하면 안 되나요?

개인정보, 고객 정보, 비밀번호, API 키, 공개되지 않은 회사 정보를 입력하지 마세요. 실제 업무 자료를 사용하기 전에는 조직의 정책과 해당 도구의 사용 조건을 확인해야 합니다.

새로운 가이드나 스킬은 어떻게 요청하나요?

제작 요청 영역에서 불편한 점과 원하는 결과를 작성해 요청문을 만드세요. 복사한 내용을 실제 운영 채널로 전달하는 방식이며, 이 연습 페이지에서는 자동 접수하지 않습니다.
