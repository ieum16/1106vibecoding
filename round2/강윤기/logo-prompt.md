# AI 표준팀 로고 만들기 — ChatGPT용 프롬프트

## 1. 기본 프롬프트
```text
AI 표준팀의 로고를 만들어 줘.
미드나이트 네이비와 청록 계열, 단순한 아이콘 + 팀 이름,
흰 배경, 정사각형.
팀은 AI 개발 가이드와 재사용 가능한 스킬을 설계한다.
서로 다른 세 개의 둥근 모듈이 정렬되어 하나의 방향을 가리키는 독창적인 추상 기하학 심벌을 디자인해 줘.
정렬된 기준, 연결되는 지식, 누구나 시작할 수 있는 안내를 표현해 줘.
Claude와 ChatGPT 로고처럼 간결하고 기억하기 쉬우며 작은 크기에서도 또렷한 인상을 원한다.
기존 로고의 방사형 실루엣이나 매듭 구성은 복제하지 말고 독자적인 구조를 만들어 줘.
굵기가 일정한 형태, 충분한 여백, 평면 벡터 같은 표현. 입체 효과·목업·복잡한 광택 없이.
글자는 정확히 ‘AI 표준팀’으로 넣어 줘.
```

## 2. 아이콘 아이디어
| 아이디어 | 이유 |
|---|---|
| 정렬된 세 모듈과 방향 표시 | 표준·스킬 조합·시작 안내 |
| 열린 사각 프레임과 한 점 | 기준 안에서 확장하는 AI 가능성 |
| 두 경로가 하나의 기준선으로 합쳐지는 형태 | 다양한 업무를 일관된 가이드로 연결 |

## 3. 다시 뽑을 때 쓰는 문장
- 더 단순하게, 24px에서도 알아볼 수 있도록 형태를 정리해 줘.
- 아이콘만 따로, 글자 없이 한 장 더 만들어 줘.
- 어두운 남색 배경에서 쓸 수 있도록 밝은 단색 버전도 만들어 줘.
- 팀 이름 철자를 정확히 ‘AI 표준팀’으로 넣어 줘.
