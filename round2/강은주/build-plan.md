# 크리에이티브 스튜디오 팀 홈페이지 제작 계획서

## 1. 만들 것
prd.md를 바탕으로 소상공인의 자동화 제작 문의를 돕는 한 장짜리 index.html을 만든다. 사용자 검토 후 제작한다.

## 2. 파일 구조
```text
team-page/
├── prd.md
├── logo-prompt.md
├── build-plan.md
├── index.html          ← 제작 단계에서 생성
└── images/
    ├── logo.png        ← 선택, 추후 추가
    └── reference.png   ← 선택, 추후 추가
```

## 3. 준비물 체크
| 준비물 | 상태 | 적용 방안 |
|---|---|---|
| 로고 | 없음 | ‘크’ 임시 글자 로고. 이미지 추가 시 자동 교체 |
| 참고 이미지 | 없음 | 보라색, 깔끔하고 믿음직한 디자인 가이드 적용 |
| 문의 이메일 | 예시 | team@example.com을 예시로 명시. 실제 운영 전 교체 |
| 실제 도구·사례 | 없음 | 점선 테두리 ‘준비 중’ 카드 |

## 4. 만드는 순서
| 단계 | 할 일 | 확인할 것 |
|---|---|---|
| 1 | 헤더, 섹션 5개, 푸터 구성 | 메뉴와 섹션 ID 연결 |
| 2 | 보라색 변수와 여백·글꼴 적용 | 대비, 읽기 편한 폭 |
| 3 | 소개와 문의 버튼 구현 | 팀 역할과 문의 목적 전달 |
| 4 | 서비스 카드 3개 구현 | 예약 관리·고객 문의 정리·견적서 작성 |
| 5 | 만든 도구 준비 중 카드 | 실제 성과로 오해할 내용 없음 |
| 6 | FAQ 2개 작성 | 가능 업무와 범위별 일정 안내 |
| 7 | 문의 준비 안내, 문구 복사 | 예시 연락처 명시, 복사 실패 시 수동 안내 |
| 8 | 햄버거 메뉴와 반응형 적용 | 375px, 태블릿, 데스크톱 표시 |
| 9 | 최종 점검 | PRD 완료 기준 확인 |

## 5. 섹션별 구현 메모
| 섹션 | 레이아웃 | 데스크톱 → 휴대폰 |
|---|---|---|
| 헤더 | 로고 왼쪽, 고정 메뉴 오른쪽 | 햄버거 메뉴 |
| 팀 소개 | 큰 제목, 보조 문구, 문의 버튼, 간결한 업무 흐름 도형 | 좌우 → 위아래 |
| 자동화 서비스 | 아이콘, 설명, 요청 예시 카드 | 3열 → 2열 → 1열 |
| 만든 도구 | 점선 테두리 준비 중 카드 | 전체 폭 |
| FAQ | 질문과 답변 | 단일 열 |
| 제작 문의 | 진한 보라색 배경, 준비 항목과 복사 버튼 | 2열 → 1열 |

이미지 생성은 필수 준비물이 아니다. 업무 흐름 도형과 임시 로고는 HTML·CSS 및 인라인 SVG로 구성한다.

## 6. 확인 방법
- index.html을 브라우저로 열어 1280px와 375px에서 레이아웃 확인.
- 모든 메뉴와 문의 버튼 이동, 고정 헤더 아래 제목 노출 확인.
- 휴대폰 메뉴 열기·닫기와 키보드 조작 확인.
- 가로 스크롤, 텍스트 잘림, 이미지 누락 여부 확인.
- 로고가 없을 때 임시 로고가 표시되는지 확인.
- 문의 문구 복사와 실패 시 직접 복사 안내 확인.
- 서버 없이 파일을 직접 열 수 있는지 확인.
- PRD 12번 완료 기준을 실제 검증 결과에 따라 체크.

## 7. 만든 뒤 고치기 예시
- 보라색을 조금 더 차분하게 바꿔 줘.
- 예약 관리 카드에 구체적인 예시를 더 넣어 줘.
- 준비 중 카드를 실제 만든 도구로 바꿔 줘.
- 실제 운영용 문의 채널로 바꿔 줘.

## 8. 디자인 참고 반영
첨부 문서의 크림 배경·명조 제목·넓은 여백·어두운 문의 영역을 반영. 강조색은 #69478B. 서비스 카드에는 실제 문의 예시를 넣고 히어로 업무 흐름은 구성 예시로 표시한다. 외부 폰트 없이 시스템 글꼴을 사용한다.
