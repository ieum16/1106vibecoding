우리가 하는 일

좋은 서비스는,
모든 순간에서 만들어지니까.

아이디어를 구체화하는 순간부터 사용자의 일상에 닿기까지. 서비스의 모든 과정에 함께합니다.

01 / PLAN

웹서비스 기획

사용자에게 필요한 기능을 찾고,
서비스의 방향과 화면 흐름을 설계합니다.

예를 들면새 서비스의 기능과 이용 흐름 정리
02 / FRONTEND

프론트엔드 개발

사용자가 직접 보고 사용하는
웹 화면을 만듭니다.

예를 들면휴대폰에서도 편하게 쓰는 화면 개발
03 / BACKEND

백엔드 개발

화면 뒤에서 데이터와 서비스 기능이
작동하도록 시스템을 만듭니다.

예를 들면데이터 처리와 서비스 기능 구현
04 / OPERATE

서비스 운영

서비스 상태를 살피고 안정적으로
사용할 수 있도록 관리합니다.

예를 들면서비스 상태 점검과 운영 관리
05 / RESPOND

장애 대응

문제의 원인을 찾아 서비스를 정상화하고,
같은 문제가 반복되지 않도록 개선합니다.

예를 들면오류 원인 분석과 복구
06 / IMPROVE

서비스 개선

사용자 의견과 운영 결과를 바탕으로
기능과 사용성을 꾸준히 다듬습니다.

예를 들면불편한 이용 과정과 성능 개선
