# DX Service팀 로고 만들기 — ChatGPT용 프롬프트

## 1. 기본 프롬프트
```text
DX Service 팀의 로고를 만들어 줘.
파란색(#1D4ED8) 계열, 단순한 아이콘 + 팀 이름,
흰 배경, 정사각형.
웹서비스 개발과 안정적인 운영을 상징하도록 연결된 두 블록을
단순한 기하학 도형으로 표현해 줘.
아이콘 옆에는 팀 이름을 정확히 “DX Service”로 넣어 줘.
깔끔하고 전문적이며 여백이 넉넉한 인상으로,
작은 크기에서도 잘 읽히게 해 줘.
입체 효과와 복잡한 장식은 제외해 줘.
```

## 2. 아이콘 아이디어
| # | 아이디어 | 이유 |
|---|---|---|
| 1 | 연결된 두 블록 | 사용자 화면과 서비스 시스템의 연결 표현 |
| 2 | 간결한 DX 모노그램 | 팀 이름을 작은 크기에서도 쉽게 인식 |
| 3 | 브라우저 창과 순환 선 | 개발부터 운영·개선까지 이어지는 업무 표현 |

## 3. 다시 뽑을 때 쓰는 문장
- “더 단순하게, 선 굵기를 일정하게 해 줘.”
- “아이콘만 따로, 글자 없이 한 장 더 만들어 줘.”
- “색을 진한 파랑 #1D4ED8로 맞춰 줘.”
- “팀 이름 철자를 정확히 DX Service로 넣어 줘.”

## 4. 홈페이지 적용
- 사용자가 로고 선택을 위임했으므로 초기 버전은 DX 글자형 인라인 SVG 로고를 사용한다.
- 이미지 생성은 초기 제작의 필수 준비물이 아니다. 이 문서는 추후 로고 이미지를 만들 때 사용할 수 있다.
- 별도 로고가 생기면 images/logo.png로 넣어 교체한다.
- 참고 화면을 활용하려면 images/reference.png로 추가한다. 현재는 참고 이미지 없이 PRD를 따른다.
