# 팀팀 — 반복 업무 자동화 솔루션 소개

## 한 줄 소개
자료 수집, 보고서 초안 생성, 일정 알림을 개발하는 가상 4명 팀의 소개 홈페이지입니다.

## 누구를 위해 만들었나요
반복 업무 자동화 솔루션을 알아보는 외부 고객을 위한 페이지입니다.

## 주요 기능
- 팀 소개, 솔루션 소개, 도입 절차, 문의 안내
- 반응형 레이아웃과 모바일 메뉴
- 확장 프로그램 아이콘을 클릭하면 새 탭으로 홈페이지 열기

## 화면
![팀팀 홈페이지](screenshot.png)

## 1라운드에서 바꾼 점
1라운드의 할 일 작성기와 다른 주제로, team-page-prd 스킬을 활용해 팀 홈페이지를 기획·제작했습니다. 짙은 남색 배경, 보라·마젠타 그라데이션, 큰 제목과 둥근 패널을 적용하고 팀 로고를 제작했습니다.

## 써 보는 법
1. chrome://extensions 에서 개발자 모드를 켭니다.
2. 압축해제된 확장 프로그램 로드로 이 폴더를 선택합니다.
3. 확장 프로그램 아이콘을 누르면 홈페이지가 새 탭으로 열립니다.
4. 확장 프로그램 없이 index.html을 직접 열어도 볼 수 있습니다.

## 안내
솔루션은 개발 중이며 화면의 흐름은 예시입니다. team@example.com은 연습용 주소로 실제 문의를 받지 않습니다. 로그인, 데이터 수집, 외부 전송 기능은 없습니다.

## 만들면서 배운 점
인터뷰를 기획 문서로 정리하고 디자인 가이드를 홈페이지에 적용하는 과정, 모바일 메뉴와 접근성, Manifest V3에서 외부 JavaScript 파일을 사용하는 방법을 배웠습니다.

## 다음에 붙이고 싶은 기능
확정된 제품 정보와 문의 채널을 반영하고, 개발 완료된 기능을 소개하고 싶습니다.
