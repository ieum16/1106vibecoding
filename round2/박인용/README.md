# 구매팀 홈페이지

## 한 줄 소개

SI 구매를 전략적으로 수행하며 비용·품질·납기·계약 위험을 함께 검토하는 구매팀의 소개 홈페이지입니다.

## 누구를 위해 만들었나요

구매를 요청하는 현업 부서와 협력업체가 구매 절차와 담당 역할을 확인할 수 있도록 만들었습니다.

## 페이지 구성

- 첫 화면: 구매 절차 확인·담당자 찾기 바로가기
- 빠른 안내: 절차, 담당 역할, 자주 묻는 질문, 문의 경로
- 구매 절차: 예시 6단계와 준비 자료
- 담당자 안내: 가상의 역할별 업무 배분
- 팀 소개: 전략적 구매의 가치
- 하는 일: 구매 전략 수립, 견적 비교, 가격·계약 협상, 협력업체 선정, 발주·납기 관리, 하도급 리스크 관리
- 자주 묻는 질문
- 문의: 예시 채널·이메일과 준비 중 안내

## 만들면서 배운 점

대화로 요구사항을 정리하고 PRD를 작성한 뒤 홈페이지로 구현했습니다. 참고 디자인의 검정 프레임과 각진 카드를 구매 안내에 맞게 흑백으로 재해석하고, 모바일에서는 세로 배치되도록 구성했습니다.

문의 정보, 구매 절차와 담당 역할은 연습용 예시입니다. 로고 이미지는 images/logo.png에 포함했으며, 홈페이지에는 사용자 요청에 따라 팀 이름을 텍스트로 표시했습니다.
