# 느린걸음 팀 홈페이지 PRD

| 항목 | 내용 |
|---|---|
| 팀 이름 | 느린걸음 |
| 한 줄 소개 | 산책 활동과 경복궁 주변 코스, 산책 기록을 소개하는 주말 산책 모임 |
| 배포 주소 | https://esemyu.vercel.app/ |

## 1. 배경과 목적

가벼운 산책 모임에 참여하고 싶은 사람이 모임의 분위기와 활동을 한눈에 파악할 수 있도록 소개 페이지를 만듭니다. 산책 장소를 지도에서 확인하고, 기록을 읽으며 참여 장면을 떠올릴 수 있게 구성합니다.

## 2. 대상과 사용 장면

- 주말에 부담 없이 걷고 싶은 사람
- 혼자 참여하기 전에 모임 분위기를 살펴보고 싶은 사람
- PC나 휴대폰으로 산책 활동과 장소를 확인하는 상황

## 3. 목표

- 모임 성격과 산책 활동을 빠르게 파악할 수 있습니다.
- 코스의 주요 장소를 네이버지도에서 확인할 수 있습니다.
- 휴대폰에서도 메뉴와 콘텐츠를 편하게 볼 수 있습니다.
- 참여 안내 확인으로 이어지는 것을 기대합니다. 실제 참여 전환 효과는 확인이 필요합니다. (가정)

## 4. 페이지 구성

1. 모임 소개: 제목, 소개 문구, 산책 찾기와 참여 안내 버튼
2. 산책 원칙: 가볍게·다정하게·가까이
3. 활동 카드: 토요일 아침 산책·골목 발견 산책·말없이 걷는 시간
4. 산책 도구: 지도·기록장·준비 중인 체크리스트
5. 경복궁 코스: 경복궁역 → 광화문 → 삼청동 개념도와 장소별 지도 링크
6. 한 걸음 기록장: 사진이 있는 예시 기록 3개, 기록별 본문 펼치기
7. 참여 안내와 자주 묻는 질문

## 5. 디자인

| 항목 | 내용 |
|---|---|
| 배경 | 검정 #121212 |
| 카드 | 짙은 회색 #181818 |
| 주요 버튼 | 초록 #1ed760 |
| 글자 | 흰색 #ffffff, 보조 글자 #b3b3b3 |
| 로고 | 현재 페이지의 첫 글자 ‘느’ 심벌을 logo.svg로 저장 |
| 사진 | 기존 Pexels·Unsplash 풍경 사진, 출처는 images/photo-sources.json |
| PC | 왼쪽 탐색 메뉴, 활동 카드 그리드, 하단 고정 안내 |
| 모바일 | 접이식 메뉴, 콘텐츠 1열 배치 |

## 6. 기능과 범위

- 메뉴와 버튼을 통한 섹션 이동
- 산책 코스의 장소별 네이버지도 새 창 열기
- 산책 기록과 FAQ 펼치기·접기
- 산책 안내 문구 복사
- 375px부터 데스크톱까지 화면 대응

코스는 자체 제작 개념도입니다. 산책 일기는 예시이며, 사진은 분위기 참고용입니다. 실제 모임 신청, 기록 작성·저장, 지도 API 연동은 이번 범위에 포함하지 않습니다.

## 7. 기술 구성

HTML·CSS·JavaScript로 구성하며 별도의 빌드가 필요하지 않습니다. GitHub 저장소를 Vercel에 연결해 배포합니다. 제출본은 확장 프로그램 아이콘으로도 새 탭에서 열 수 있습니다.

## 8. 완료 기준

- 메뉴와 참여 안내 버튼이 해당 영역으로 이동합니다.
- 지도 링크와 기록 펼치기가 동작합니다.
- 사진이 정상 표시됩니다.
- 모바일 화면에 가로 넘침이 없습니다.
- 기획서·로고·배포 주소를 제출 폴더에 포함합니다.
