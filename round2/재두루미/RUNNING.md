# 뉴스 수집

밝고 친근한 카드형 뉴스 모음. 분야 선택, 현재 수집 목록 내 키워드 검색, 수동 새로고침, 한국어 요약과 원문 이동을 제공합니다.

## 실행

Node.js 22 이상이 필요합니다. 외부 패키지를 설치할 필요는 없습니다.

```powershell
cd "round2\재두루미"
npm.cmd start
```

또는 `start-news.cmd`를 더블클릭하세요. 브라우저에서 [http://localhost:4317](http://localhost:4317)을 열고 **새로고침**을 누르세요. 종료는 실행 터미널에서 Ctrl+C입니다. HTML 파일 더블클릭으로는 실제 뉴스 수집이 작동하지 않습니다.

## 실제 연결 범위

| 출처 | 구현 | 필요한 설정 |
|---|---|---|
| 전자신문 | 공식 AI·IT·경제·국제 RSS 수집 | 없음 |
| BBC | 공식 World·Technology RSS 수집 | 수집은 설정 불필요, 한국어 번역·요약은 Gemini 키 필요 |
| 네이버 | 분야별 공식 뉴스 검색 API | NAVER_CLIENT_ID, NAVER_CLIENT_SECRET |
| 네이트 | 연결 제한 안내와 사이트 바로가기 | 현재 robots.txt의 일반 자동 수집 제한으로 자동 수집 미지원 |

네이버·네이트까지 네 출처가 모두 자동 연결된 완성 상태는 아닙니다. 네이트의 허용된 API/제휴 피드가 확보되면 연결부를 추가해야 합니다. 부동산 기사도 실제 연결된 수집처에 관련 기사가 없으면 빈 목록일 수 있습니다.

## 한국어 요약과 번역 설정

1. `.env.example`을 `.env`로 복사합니다.
2. 사용할 서비스의 키를 로컬 `.env`에 입력합니다. 대화·HTML·Git에는 붙여 넣지 마세요.
3. 서버를 재시작하고 새로고침을 누릅니다.

```dotenv
NAVER_CLIENT_ID=
NAVER_CLIENT_SECRET=
GEMINI_API_KEY=
GEMINI_MODEL=gemini-2.5-flash
```

네이버는 개발자 센터에서 뉴스 검색 API 사용 설정이 필요합니다. Gemini 모델은 계정에서 사용 가능한 모델 ID로 변경할 수 있습니다. 모델 호출 시 수집한 제목과 제공 설명을 Google Gemini API에 전송하며, 해당 서비스의 사용량/과금이 적용됩니다. 원문 전문이나 사용자 검색어는 보내지 않습니다.

- AI 설정 전: 한국어 제공 설명에 완전한 문장 3개가 있으면 그 문장들을 발췌합니다. 카드에 **3문장 발췌**라고 표시합니다.
- AI 설정 후: 제공 설명을 근거로 한국어 제목과 3문장 요약을 요청합니다. BBC 영어 기사도 한국어로 처리합니다.
- 근거가 부족하거나 AI 호출이 실패하면 없는 내용을 채우지 않고 요약 불가 사유와 원문 설명을 표시합니다. BBC 번역을 설정하지 않으면 영어 원문 제목·설명을 표시합니다.
- 실제 발행 매체를 알 수 없는 네이버 결과는 `발행 매체 확인 불가`로 표시합니다. 네이버 API의 날짜는 원문 발행일과 다를 수 있어 `제공` 시각으로 구분합니다.

## 수집 동작

- 자동 예약 수집 없음. 페이지 진입 시 이전 저장 자료를 보여 주고 버튼을 누를 때만 외부 수집을 실행합니다.
- 최근 48시간, 최대 40건. 발행 시각이 없으면 `시각 미제공`으로 표시합니다.
- 분야와 키워드 필터를 함께 적용합니다. 검색 범위는 현재 수집한 기사의 제목·원문 제목·요약입니다.
- 새로고침 중 진행 상태를 표시하며 중복 실행을 막습니다. 최소 재요청 간격은 20초입니다.
- URL의 추적 정보를 제거해 같은 기사를 합치고 수집 경로를 보존합니다. 제목만 비슷한 서로 다른 기사를 임의로 합치지는 않습니다.
- 실패한 출처의 이전 기사는 최근 48시간 범위에서 유지하고 이전 자료임을 표시합니다.
- `.cache/news.json`에 이전 수집 결과와 AI 요약을 저장합니다. 같은 내용·모델의 성공한 요약을 재사용합니다. 캐시와 `.env`는 Git에서 제외됩니다.
- 기본 서버는 로컬 컴퓨터에서만 접속할 수 있도록 127.0.0.1에 바인딩됩니다. 공개 배포는 포함하지 않았습니다.

## 화면 변경

- 색상과 모서리 등은 `index.html`의 `:root`에서 바꿀 수 있습니다.
- `images/logo.png`를 넣으면 글자 아이콘 대신 로고가 표시됩니다.
- 문의 주소는 예시이며 전송 기능은 없습니다.

## 검증

```powershell
npm.cmd test
```

RSS·HTML 정리, 잘못된 URL, 중복/날짜 필터, 근거 부족 요약, 네이버/AI 모의 응답, 부분 실패 보존, 캐시 복원과 동시 새로고침을 검증합니다. AI 모의 테스트는 실제 모델 요약 품질이나 계정 연결 성공의 증거가 아닙니다.
