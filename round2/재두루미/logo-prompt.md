# 뉴스 수집 로고 만들기 — ChatGPT용 프롬프트

## 1. 기본 프롬프트

```text
뉴스 수집 팀의 로고를 만들어 줘.
밝은 파랑(#2563EB) 계열에 청록(#0F766E)을 포인트로 쓰고,
단순한 아이콘 + 팀 이름, 흰 배경, 정사각형.
여러 장의 뉴스 카드가 하나로 모이는 모습을 단순한 도형으로 표현해 줘.
글자는 정확히 '뉴스 수집'으로 넣어 줘.
밝고 친근하고 읽기 쉬운 느낌으로, 작은 홈페이지 헤더에서도 알아보기 쉽게 만들어 줘.
실제 언론사나 포털의 로고는 사용하지 마.
```

## 2. 아이콘 아이디어

| # | 아이디어 | 이유 |
|---|---|---|
| 1 | 겹친 카드 3장과 짧은 줄 | 여러 기사를 한곳에 모으고 요약하는 성격 |
| 2 | 둥근 돋보기 안의 작은 신문 | 키워드로 관심 뉴스를 찾는 기능 |
| 3 | 네 개 점이 중앙 카드로 모이는 모양 | 네 분야와 여러 수집처를 연결 |

## 3. 다시 뽑을 때 쓰는 문장

- 더 단순하게, 작은 크기에서도 보이도록 선과 글자를 또렷하게 만들어 줘.
- 아이콘만 따로, 글자 없이 한 장 더 만들어 줘.
- 장식을 줄이고 여백을 넓혀 줘.
- 팀 이름 철자를 정확히 '뉴스 수집'으로 넣어 줘.

## 4. 사용 방법

현재 로고 이미지는 없으며 제작 시작을 위해 꼭 만들 필요는 없다. 초기 화면은 글자 로고를 사용한다.

나중에 이 프롬프트를 ChatGPT에 붙여 넣어 만든 이미지를 이 대화에 올리거나 images/logo.png로 넣으면 교체할 수 있다. 참고 화면이 생기면 images/reference.png로 함께 보관한다. 현재 단계에서는 이미지 생성이나 파일 업로드를 기다리지 않는다.
