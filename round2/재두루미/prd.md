# 뉴스 수집 — 뉴스 서비스 PRD

## 한 줄 소개

AI·IT, 경제·금융, 부동산, 해외 토픽 뉴스를 한곳에 모아 한국어 요약과 원문 링크를 제공하는 뉴스 서비스입니다.

| 항목 | 내용 |
|---|---|
| 문서 상태 | 초안 v0.1 · 제작 전 검토용 |
| 작성일 | 2026-11-06 |
| 작성자 | 뉴스 수집 |
| 관련 문서 | logo-prompt.md, build-plan.md |

> PRD는 누구를 위해 무엇을 만들고, 어떻게 완성을 확인할지 정리한 기획서입니다.

## 1. 배경 · 문제

관심 분야의 뉴스를 보려고 여러 사이트를 오가며 제목과 본문을 읽어야 한다. 지정한 사이트의 기사를 한곳에 모으고 한국어로 짧게 요약해, 읽을 기사를 고른 뒤 원문으로 이동하게 한다.

팀 소개보다 실제 최신 뉴스 수집·요약을 중심에 둔다. 사용자의 요청에 따라 단일 정적 소개 페이지에서 프런트엔드와 수집·요약 서버를 갖춘 서비스로 범위를 확장한다.

## 2. 목표와 성공 기준

| 목표 | 성공 기준 |
|---|---|
| 관심 분야별 뉴스 탐색 | AI·IT, 경제·금융, 부동산, 해외 토픽 탭이 목록을 바꾼다 |
| 빠른 내용 파악 | 정상 요약 카드에 한국어 제목, 원문 제목, 근거 있는 한국어 요약 3문장, 매체, 발행 시각, 원문 링크가 보인다 |
| 최신 기사 갱신 | 새로고침 버튼이 실제 수집 요청을 보내고, 성공한 출처별 갱신 시각을 바꾼다 |
| 키워드 탐색 | 현재 수집 목록의 제목·원문 제목·요약에서 검색하고 분야 필터와 함께 적용한다 |
| 신뢰할 수 있는 상태 안내 | 일부 매체 실패, 요약 실패, 검색 결과 없음, 이전 자료 표시를 구별한다 |

## 3. 대상 사용자

| 대상 | 궁금한 것 | 페이지가 줘야 할 답 | 기대 행동 |
|---|---|---|---|
| 특정 분야 뉴스를 찾는 사람 | 관심 분야에 어떤 새 소식이 있나 | 분야별 최신순 기사와 한국어 요약 | 요약을 읽고 원문으로 이동 |

## 4. 범위

### 이번에 만드는 것

- 지정 수집처: 네이버 뉴스, 네이트 뉴스, BBC, 전자신문.
- 분야: AI·IT / 경제·금융 / 부동산 / 해외 토픽. 전체 탭도 제공한다(가정).
- 사용자가 새로고침을 누를 때 수집하고, 같은 기사 중복을 제거한다.
- 모든 기사를 한국어로 요약하고 원문 제목도 보존한다. 한국어 기사도 원문 제목을 별도 표시한다.
- 한국어 제목 + 요약 3문장 + 원문 제목 + 매체·발행 시각 + 원문 링크 카드.
- 키워드 검색, 최신순 정렬, 모바일 대응.
- 출처별 연결 상태, 마지막 성공 시각, 실패 및 빈 화면 안내.
- 글자 로고, 짧은 팀 소개, 예시 문의 정보(가정).

### 후속 범위

로그인, 북마크, 알림, 예약 수집, 유료 기사 접근, 지정하지 않은 매체의 별도 수집, 기사 전문 재게시, 공개 호스팅·도메인 설정.

## 7. 콘텐츠 상세

### 7-1. 한 줄 소개

- 제목: 관심 뉴스, 한눈에 가볍게.
- 보조 문구: AI·IT부터 해외 토픽까지, 한국어 요약으로 읽고 원문에서 더 알아보세요.
- 버튼: 새로고침 / 원문 보기.

### 7-2. 분야별 카드

| 분야 | 포함 내용 (가정) | 주 수집 후보 |
|---|---|---|
| AI·IT | 인공지능, 소프트웨어, 반도체, 디지털 기술 | 전자신문, 네이버, 네이트, BBC |
| 경제·금융 | 산업, 금융, 시장, 경제 정책 | 네이버, 네이트, 전자신문, BBC |
| 부동산 | 주택, 청약, 임대차, 부동산 정책 | 네이버, 네이트 |
| 해외 토픽 | 해외 사회, 문화, 국제 이슈 | BBC, 네이버, 네이트 |

기사 한 건에 대표 분야 하나를 지정한다(가정). 관련 없는 기사를 억지로 분야에 넣지 않는다.

### 7-3. 기사 데이터

| 필드 | 의미 |
|---|---|
| id / canonicalUrl | 출처 ID 또는 정규화된 링크로 중복 식별 |
| source | 수집 경로: naver / nate / bbc / etnews |
| publisher | 실제 발행 매체. 알 수 없으면 확인 불가 표시 |
| originalTitle / titleKo | 원문 제목 / 한국어 제목 |
| summarySentences | 근거에 기반한 한국어 문장 3개. 성공 시에만 표시 |
| summaryStatus / summaryBasis | 완료·불가·오류 및 전문·제공 설명 등 요약 근거 범위 |
| category / language | 대표 분야 / 원문 언어 |
| publishedAt / fetchedAt | 원문 발행 시각 / 수집 시각. 발행 시각 미제공 시 임의 생성 금지 |
| originalUrl / portalUrl | 원문 및 포털 기사 링크. 원문 미확인 시 포털 링크임을 표시 |

표시 시각은 한국 시간으로 통일하고 날짜까지 볼 수 있게 한다(가정). 검색은 현재 불러온 기사에만 적용하며 사이트 전체 검색으로 표현하지 않는다.

### 7-4. 문의

team@example.com은 예시 주소다. 문의 전송 기능이나 응답 시간은 약속하지 않는다.

## 9. 반응형 · 접근성

- 데스크톱 3열 → 태블릿 2열 → 휴대폰 1열.
- 375px 화면에서 좌우 여백 16px, 가로 넘침 없음. 640px 아래 메뉴 접기.
- 키보드로 검색·탭·새로고침·원문 링크 조작, 포커스 표시, 입력 레이블 제공.
- 로딩·완료·실패를 보조 기술에 알린다. 색만으로 상태를 구분하지 않는다.
- 새 창 링크는 알맞은 보안 속성을 지정하고, 수집한 제목·본문은 HTML로 직접 실행하지 않는다.

## 10. 기술 조건

- 화면은 index.html 하나에 CSS·JS를 넣는다. 실제 수집·요약을 위해 별도 서버가 필요하므로 더블클릭만으로 전체 기능을 제공하는 조건은 적용하지 않는다.
- 브라우저 → 동일 출처 서버 API → 지정 출처 수집 → 중복 제거·분류 → 한국어 요약 → 화면 반환.
- 네이버 검색 API는 클라이언트 ID·시크릿 설정이 필요하다. 서버 환경 변수로만 관리하고 HTML·저장소에 넣지 않는다.
- 네이버 API는 검색 결과를 제공하므로 네이버 뉴스 메인 전체 수집과 같다고 보장하지 않는다. 분야별 검색어와 최신순 조건으로 후보를 모은다(가정).
- BBC·전자신문은 공식 RSS를 우선 검토한다. RSS 제공 자체가 전문 수집·번역·재게시 허용을 뜻하지 않으므로 실제 연결 시 제공 범위와 조건을 확인한다.
- 네이트의 공식 API/RSS 연결 방법은 이번 조사에서 확정하지 못했다. 구현 시 공개 뉴스 페이지의 제공 조건과 기술적 접근을 확인한다. 연결할 수 없으면 실패 상태를 명확히 표시하며, 4개 모두 연동 완료로 처리하지 않는다.
- 네이버·네이트는 포털 경로와 실제 발행 매체를 구분한다. 지정 사이트에서 노출된 기사를 대상으로 하고, 외부 원문 링크는 이동용으로 허용한다(가정). 외부 발행사의 본문까지 자동 요청하는 범위는 연결 조건에 따라 확정한다.
- 요약 제공자·모델은 미정. 서버의 교체 가능한 연결부로 만들고, 접근 가능한 기사 내용/설명만 근거로 요약한다. 제목만으로 3문장을 만들어 내지 않는다.
- 충분한 근거가 없거나 설정이 없으면 요약 불가와 이유를 표시한다. 제공 설명만 쓴 경우 '제공 설명 기반'으로 표시한다.
- 초기 표시 범위는 최근 48시간, 최대 40건(가정). 날짜 없는 기사는 별도 표시한다. 버튼 실행 시 재조회하되 연속 클릭을 제한하고 이미 요약한 기사는 캐시를 활용한다.
- 정기 수집 없음. 재방문 시 이전 자료와 수집 시각을 보여 주고 사용자 실행으로 갱신한다(가정).
- 매체별 시간 제한과 부분 성공 처리. 실패 시 이전 정상 기사를 유지하고 오래된 자료임을 표시한다.

### 확인한 공식 자료 (2026-11-06)

- [네이버 뉴스 검색 API](https://developers.naver.com/docs/serviceapi/search/news/news.md): 검색 응답과 인증 준비사항.
- [BBC 뉴스 피드 안내](https://support.bbc.co.uk/platform/feeds/NewsFeeds.htm): 피드 목록과 이용 조건 연결.
- [전자신문 RSS 안내](https://rss.etnews.com/): 공식 RSS 목록.
- [네이트 뉴스](https://news.nate.com/): 뉴스 홈 확인. 공식 수집 API/RSS는 미확정.

위 자료는 연결 방식 조사 근거다. 서버에서 피드·API를 호출하거나 한국어 요약을 검증한 상태는 아니다.

## 12. 완료 기준

- [ ] 실제 지정 출처 4개의 연결 상태를 각각 검증했다.
- [ ] 네 출처 중 미연결 항목이 있으면 제한 사항을 명시하고 전체 연동 완료라고 하지 않는다.
- [ ] 새로고침으로 실제 수집 결과가 바뀌며 발행 시각과 수집 시각을 구분한다.
- [ ] 정상 요약 카드가 요청한 모든 필드를 갖추고 요약 3문장을 원문과 대조했다.
- [ ] 영어 기사도 한국어 제목·요약과 원문 제목을 함께 표시한다.
- [ ] 분야 선택과 키워드 검색이 함께 동작하고 빈 결과를 안내한다.
- [ ] 중복 기사, 일부 출처 실패, 요약 불가, 설정 미완료를 처리한다.
- [ ] 원문 링크가 실제 기사로 연결되고 출처 표기가 정확하다.
- [ ] 데스크톱과 375px 화면에서 레이아웃·메뉴·키보드 조작을 확인했다.
- [ ] 서버 비밀값이 HTML·응답·로그·커밋에 포함되지 않는다.

## 13. 열린 질문

- 파랑·청록 색상, 초기 48시간·40건, 대표 분야 하나, 목록 내 검색은 제안 기본값(가정)이다.
- 네이버·네이트는 포털에 게재/검색된 타 언론사 기사도 포함하는 해석이다(가정).
- 네이버 인증 설정과 요약 제공자 선택은 실제 연동 시 필요하다. 비밀값은 대화에 올리지 않고 로컬 환경에 설정한다.
- 네이트 연결 방식과 각 출처의 요약 입력 확보 범위는 구현 조사에서 확정한다.
- 로고 이미지는 선택 사항. 현재는 글자 로고로 진행한다.
