# 구현·검증 기록

검증일: 2026-11-06 (한국 시간)

## 구현 결과

- index.html: 밝은 파랑과 민트 포인트, 카드형 목록, 분야 선택, 키워드 검색, 수동 새로고침, 출처별 상태, 팀 소개.
- server/: Node.js 기본 모듈만으로 실행하는 로컬 수집·요약 서버. 외부 패키지 설치 불필요.
- .env.example / README.md / start-news.cmd: 연동 설정과 실행 안내.
- previews/desktop.png, previews/mobile.png: 실제 뉴스가 표시된 브라우저 화면.

PRD에서 제안한 3열 카드는 읽기 편한 본문 폭과 출처 상태 패널을 확보하기 위해 1280px에서 2열, 1600px 이상에서 3열, 휴대폰에서 1열로 구현했다.

## 실제 네트워크 검증

| 항목 | 관측 결과 |
|---|---|
| 전자신문 RSS | AI·IT·경제·국제 피드 조회 성공 |
| BBC RSS | World·Technology 피드 조회 성공 |
| 최종 수집 | 최근 48시간 내 기사 40건 표시 |
| 최종 3문장 발췌 | 21건. 문장이 부족한 한국어 기사 10건은 보류 |
| BBC 번역 | 9건은 AI 미설정 상태를 표시. 실제 번역 호출은 미검증 |
| 네이버 | 인증 미설정 상태 표시. 실제 API 인증 호출 미검증 |
| 네이트 | robots.txt의 일반 자동 수집 제한 확인. 자동 수집하지 않음 |

기사와 건수는 검증 시점의 결과이며 이후 갱신하면 달라질 수 있다. 테스트용 뉴스나 가짜 최신 기사는 넣지 않았다. 요약은 기사 전문이 아닌 RSS·검색 제공 설명을 근거로 한다.

## 자동 테스트

`npm.cmd test`: 9개 통과.

- RSS CDATA·엔티티·날짜 처리, HTML 정리와 위험한 링크 차단.
- 분야 분류, 기사 중복과 출처 병합, 48시간·미래 날짜 필터.
- 불충분한 설명을 임의로 3문장으로 늘리지 않음.
- 소수점 수치(20.79%, 1.9%)가 문장 분리로 잘리지 않음.
- 미설정 네이버·제한된 네이트에 수집 요청을 보내지 않음.
- 네이버 모의 API 응답과 Gemini 모의 한국어 요약 응답 처리.
- 출처 실패 시 이전 기사 보존, 저장 자료 복원, 동시 실행 방지와 요약 캐시.

Gemini 모의 테스트는 실제 계정 인증, 과금, 번역 및 사실 정확성을 검증한 것은 아니다. 실제 AI 연결은 GEMINI_API_KEY 설정 후 확인해야 한다.

## HTTP·브라우저 검증

- `/`와 `/api/news`: HTTP 200.
- `/.env`와 `/server/index.mjs`: HTTP 404. 서버 파일을 정적 공개하지 않음.
- 전용 요청 헤더 없는 새로고침: HTTP 403.
- 브라우저의 새로고침 버튼으로 실제 수집 실행 및 완료 상태 확인.
- AI·IT 분야 + '클라우드' 검색: 관련 기사 2건 표시.
- 없는 검색어: 빈 결과 안내. 초기화 버튼으로 전체 기사 40건 복귀.
- 375px: 1열 카드, 접이식 메뉴 열기·닫기, 가로 넘침 없음.
- 1280px: 카드 2열과 출처 패널, 가로 넘침 없음.
- 기사 제목·원문 제목·3문장 발췌·매체·발행 시각·원문 링크의 DOM 표시 확인.

## 남은 연동 조건

1. 네이버 수집에는 사용자 로컬 환경의 공식 API 인증 설정이 필요하다.
2. 전체 기사 한국어 AI 요약·BBC 번역에는 사용 가능한 Gemini 모델과 키가 필요하다.
3. 네이트는 허용된 API 또는 제휴 피드가 확보되어야 자동 수집을 추가할 수 있다.

기획서의 전체 출처 연결 및 전체 한국어 요약 완료 기준은 위 조건 때문에 미충족이다. 현재 결과를 네 출처 전체 연동 완료로 표현하지 않는다. 공개 호스팅은 요청 범위에 포함되지 않았으며 로컬 실행용으로 전달한다. 검증용 서버는 점검 후 종료하고, 사용 시 start-news.cmd로 다시 실행한다.
