# GAStudio 팀 홈페이지 제작 계획서

## 1. 만들 것
사무 부서가 자동화 가능한 업무를 이해하고 요청 초안을 준비하는 한 장짜리 팀 소개 페이지. 기준 문서는 prd.md이며 홈페이지 제작은 사용자 확인 후 시작합니다.

## 2. 파일 구조
```text
team-page/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html          ← 제작 확인 후 생성
└─ images/             ← 제작 단계에서 필요한 경우 생성
   ├─ logo.png         ← 선택, 없으면 임시 G 로고
   └─ reference.png    ← 추가 참고 이미지가 있을 때
```

## 3. 준비물 체크
| 준비물 | 상태 | 처리 |
|---|---|---|
| 로고 | 미제공 | 임시 G 로고 또는 사용자 이미지 |
| 참고 디자인 | 텍스트 가이드 제공 완료 | 웜 뉴트럴·전체 폭 섹션·무그림자 구성 반영 |
| 참고 이미지 | 미제공 | 텍스트 가이드와 PRD 기준 제작 |
| 요청·문의 채널 | 미정 | 준비 중 표시, team@example.com은 예시로 명시 |

## 4. 만드는 순서
| 단계 | 할 일 | 확인 |
|---|---|---|
| 1 | 헤더·7개 본문 영역·푸터 | 상단 4개 메뉴 연결 |
| 2 | 디자인 변수·레이아웃 | 초록 강조 섹션, 차콜 버튼, 웜 뉴트럴 배경 |
| 3 | 소개·3개 업무 예시 | 확정 팀 설명·업무 반영 |
| 4 | 도구 준비 중 카드 | 점선·준비 중 배지 |
| 5 | 요청 초안 입력·복사 | 입력 검증, 성공·실패 안내, 접수 여부 구분 |
| 6 | FAQ·1:1 문의 | 키보드 사용, 문의 초안 복사 |
| 7 | 반응형·접근성 | 375px, 1280px, 초점 표시, 모바일 메뉴 |
| 8 | 최종 점검 | PRD 완료 기준 확인 |

## 5. 섹션별 구현 메모
| 섹션 | 레이아웃 | 모바일 |
|---|---|---|
| 헤더 | 흰 배경, 초록 로고, 4개 메뉴, 고정 | 640px 미만 햄버거 |
| 소개 | 넓은 웜 뉴트럴 영역, 큰 문구, 금색 선 1개 | 제목 축소, 버튼 세로 배치 |
| 업무 예시 | 3열, 그림자 없는 카드 | 2열 → 1열 |
| 만든 도구 | 준비 중 카드 | 1열 |
| 자동화 요청 | 안내와 초안 입력을 나란히 | 위아래 배치 |
| FAQ | details/summary 목록 | 동일 구조 |
| 1:1 문의 | 초록색 전체 폭 영역, 상담 초안·예시 채널 | 1열 |

## 6. 확인 방법
- index.html을 데스크톱·375px 폭으로 열어 가로 넘침과 레이아웃 확인.
- 메뉴 이동, 햄버거 열기·닫기, FAQ 펼치기, 키보드 초점 확인.
- 요청·문의 복사를 시도하고 미지원 환경의 수동 복사 안내 확인.
- 접수 서버가 없으므로 제출 완료·메일 발송 완료 같은 표시가 없는지 확인.
- 첨부 가이드의 그림자 없음, 전체 폭 직각 섹션, 균일한 카드 모서리, 절제된 색 사용 확인.
- PRD 12번 완료 기준을 점검하고 실제 확인 여부를 구분해 보고.

## 7. 만든 뒤 고치기 예시
- 업무 카드를 하나 더 넣어 줘.
- FAQ에 처리 기간 질문을 추가해 줘.
- 실제 요청 채널로 연결해 줘.
- 임시 로고를 새 로고로 교체해 줘.
