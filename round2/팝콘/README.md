# 팀요아정 홈페이지

## 한 줄 소개

100명 규모의 팀요아정 재직자가 업무와 인수인계, 일정, 업무 파일을 한곳에서 확인하는 홈페이지입니다.

## 누구를 위해 만들었나요

팀요아정 재직자가 내 업무와 인수받을 일을 찾고, 이번 주 일정과 업무 파일 위치를 확인할 수 있도록 만들었습니다.

## 페이지 구성

- 팀요아정 소개와 팀원 프로필
- 전체업무 검색과 팀·상태 필터
- 일정관리
- 관리일지
